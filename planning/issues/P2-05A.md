# P2-05A 번호·이름 주석 읽기

## 문제와 시작 상태

본문의 나무위키식 주석 `[* 내용]`·`[*이름 내용]`·`[*이름]`이 아직 문자로만 표시됨. 부연 설명을 본문과 분리하고 같은 설명을 재참조하는 읽기 기능 필요. Mermaid 단계 main `37206ca` 반영, 해당 CI/Pages 성공 확인 뒤 구현 시작. Next 정적 Pages·Spring/MySQL/JDBC 세션·OCI 계약 유지.

## 구현 범위

- 이름 없는 주석은 이름 주석의 수와 독립적으로 문서 전체 등장 순서대로 1,2,3 번호. 이름 있는 주석은 이름으로 표시하고 같은 이름은 처음 내용이 있는 정의를 재사용. 앞선 이름 참조도 문서에 유효한 정의가 있으면 연결하며 미정의/빈/미닫힌/중첩 주석은 원문 보존. 이름 공백/닫는 대괄호 불허. 번호와 같은 문자열의 이름도 내부 ID 충돌 없음.
- 입력은 UTF-8 1MiB·주석 후보512개, 내용2048 UTF-16 code units·이름64 codepoints 상한. 전체 입력/후보 초과는 문서 원문으로, 개별 과대/미닫힘은 해당 후보 또는 줄 원문으로 대체. 선형 탐색으로 잘못된 대괄호가 반복되는 입력의 처리 비용 제한.
- 한 줄의 인라인 주석 내용에 굵게·기울임·코드·인라인 수식·안전 링크 허용. 대괄호 짝 맞추기와 이스케이프/코드/수식 경계로 일반 링크·위키 모양 텍스트의 닫는 괄호 보존. 위키 대상 조회는 이번 단계 없이 문자 보존. 주석 내부 이미지/HTML/다른 주석·블록 문법 실행 없음. 여러 줄의 불명확한 주석은 원문 유지.
- 코드/인라인 코드·수식/도식·URL·링크 라벨·이미지 주소/설명·raw HTML 속 주석 표기는 해석 제외. 본문·표·안전 접기의 전체 문서 범위에서 동일한 주석 정의/번호 사용. 원문과 편집 모델의 LF/CRLF 무수정 왕복·다른 블록 수정 시 기존 내용 유지. 주석 안 이미지 모양 텍스트는 첨부 연결 목록에서 제외.
- 본문 위첨자와 끝의 `주석` 목록. 위첨자→주석 항목, 항목→첫 참조의 키보드/클릭 이동 및 잠깐 강조. 문서별 ID 범위로 중복 이름/여러 Markdown 인스턴스 충돌 차단. 접힌 details 안 첫 참조로 돌아갈 때 부모 접기 열기. 원문 이름을 임의 HTML/id로 직접 삽입하지 않음.
- hover 가능한 환경에서는 위첨자와 키보드 초점에 설명 말풍선. 화면 가장자리 16px 여백, 최대340px, 위 공간 부족 시 아래 배치, 스크롤/경로/원문/계정 변경 시 닫힘. 모바일 탭은 주석 목록 이동. Escape로 닫힘, reduced-motion 존중. PRIVATE 로그아웃 시 말풍선/목록/참조 제거.
- 에디터의 블록별 미리보기는 이번 단계 주석 문자를 유지해 문서 전체 번호로 오인하게 만들지 않음. 문서 전체 주석 미리보기와 커서 삽입 버튼은 P2-05B에서 연결. 이 구분은 구현 완료와 함께 문서화.
- 한국어 JSDoc·README·Markdown/편집 안내 및 전달 체크리스트 갱신. 신규 라이브러리는 필요성이 입증되지 않으면 추가 없음.
