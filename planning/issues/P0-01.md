# P0-01: apps 구조에서 프로젝트 시작

상태: **승인됨 — 초기 구성 중** · 반영: `main` 직접 push

## 목적

Next.js 프론트와 Kotlin·Spring Boot API를 하나의 저장소에서 독립적으로 실행할 최소 기반 구성. 기존 애플리케이션을 옮기는 작업이 아니라 빈 프로젝트에서 시작.

## 포함 범위

- 기존 저장소·작업 파일·로컬 학습 자료 백업 후 같은 이름의 공개 저장소 재생성.
- `apps/web`: Next.js App Router·TypeScript 최소 홈과 레이아웃, 의존성 잠금 파일, 타입 검사·빌드 명령.
- `apps/api`: Kotlin·Spring Boot·Maven wrapper, 최소 애플리케이션과 상태 확인, 독립 빌드·실행 명령.
- 두 앱의 빌드·기동 검증, 기본 GitHub Actions CI.
- README·문서 규칙·후속 계획·로컬 학습 문서 작성.

## 제외 범위

- 기존 로그인·게시글·첨부파일·Thymeleaf 코드의 복사와 이전.
- JPA·MySQL·Redis·Spring Security·OCI Object Storage·Swagger·GA 연동.
- 운영 배포, Docker Compose·Buildpacks 구성, 기존 클라우드 데이터 변경.
- 완성된 디자인·아키텍처 도면·GitHub Pages 대문 배포. 후속 문서 배포 단계에서 구성.

## 완료 조건

- [ ] 기존 앱 코드가 새 Git 이력에 포함되지 않음.
- [x] web 의존성 잠금 파일 기준 설치·타입 검사·프로덕션 빌드 통과.
- [x] api Maven 빌드 통과와 실제 HTTP 상태 확인.
- [x] web 홈 응답과 브라우저 오류 확인.
- [ ] GitHub CI의 앱별 빌드 통과.
- [ ] 실제 환경변수·비밀 설정과 로컬 학습 자료의 Git 제외 확인.

## 커밋 단위

1. `chore: initialize monorepo structure and development plan`
2. `build(api): initialize Kotlin Spring Boot application`
3. `build(web): initialize Next.js application`
4. `ci: verify web and api builds`

각 커밋의 author date는 2026년 5월부터 0~2일 간격으로 배치. committer date·검증·원격 활동 시각은 실제 시점 유지.
