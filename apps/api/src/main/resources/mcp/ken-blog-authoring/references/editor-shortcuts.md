# 웹 편집기 입력과 저장 원문의 차이

이 표는 웹의 `shortcut-help.tsx`와 `block-editor.tsx` 기준. MCP `body`는 오른쪽의 **저장 원문**을 직접 작성. 입력 명령의 확정 키는 웹에서만 동작.

| 웹 입력 | 확정 | 만들어지는 블록 / 저장 원문 |
| --- | --- | --- |
| `#`, `##`, `###` | 공백 | `# 제목`, `## 제목`, `### 제목` |
| `-` (`*`도 가능) | 공백 | `- 항목` 글머리 |
| `1.` | 공백 | `1. 항목` 번호 목록 |
| `[]` 또는 `[ ]` | 공백 | `- [ ] 항목` 할 일; 체크하면 `- [x]` |
| `>` | 공백 | `<details>`·`<summary>` 접기. 저장 인용문 아님 |
| `|` | 공백 | `> 인용문`. 저장 표 아님 |
| `/접기` 또는 `/toggle` | Enter | `<details>` 접기 |
| `/표` 또는 `/table` | Enter | 2열 머리글과 빈 본문 1행의 GFM 기본 표 |
| `\| 이름 \| 값 \|` 모양의 외곽 파이프 머리글 | Enter | 해당 머리글의 GFM 표; 구분 행을 자동 생성 |
| `` ```java `` 등 언어명 | Enter | 닫는 fence가 있는 코드 블록 |
| `` ```mermaid `` | Enter | 정확한 소문자 `mermaid` fence의 도식 |
| `$$` | Enter | 독립 `$$` 두 줄의 KaTeX 블록 |
| `---` | Enter | 구분선 `---` |
| `$x^2$`, `[[글 제목]]`, `[[제목\|표시명]]`, `[* 내용]`, `[*A 내용]`, `[*A]` | 입력 중 | 인라인 원문 그대로 저장. 위키·주석은 문장 중간에서도 동작 |
| 이미지 버튼·붙여넣기·삽입선에 파일 놓기 | 업로드 완료 | `![캡션\|w=100\|a=center](attachment:ID)` 이미지 블록 |

기본 표는 생성 직후 셀을 채워야 하고, MCP에서 `/표` 텍스트를 보낸다고 표가 만들어지지 않음. 표 머리글 뒤에 반드시 `| --- | --- |` 구분 행을 직접 작성. 코드와 수식은 닫는 구분자를 넣어야 렌더됨.

| 키 / 조작 | 웹 동작 |
| --- | --- |
| 태그 입력 뒤 Enter | 태그 추가 |
| Enter | 다음 블록; 빈 목록은 일반 문단으로 전환; 접기 제목에서는 안쪽 내용으로 이동하고 접기 안 빈 줄에서는 밖으로 이동 |
| Backspace | 빈 블록을 일반 문단으로, 다시 누르면 위 블록과 합침 |
| Esc | 선택 해제; 코드·도식·수식 편집을 닫고 렌더 |
| Ctrl/⌘ + Enter | 코드·도식·수식 내부에서 다음 문단 생성 |
| ↑ ↓ | 블록 사이 이동 |
| Tab / Shift+Tab | 앞 접기 안으로 들여쓰기 / 밖으로 내어쓰기 |
| 손잡이 Shift+클릭 | 연속 블록 선택 |
| 손잡이 Ctrl/⌘+클릭 | 블록 다중 선택 추가·제거 |
| 손잡이 Alt+↑ ↓ | 선택 블록을 함께 한 칸 이동 |
| ⋮⋮ 드래그 | 선택 블록을 삽입선 위·아래로 이동 |

키보드·드래그와 마지막의 빈 입력 줄은 웹 편집 상태. 저장 Markdown에는 해당 조작이나 화면 전용 줄이 기록되지 않음.
