# ken.blog 전체 전달 범위·수용 체크리스트

## 기준과 판정

- 설계 원본: 인수인계 첨부 `ken-blog-handoff.zip`의 `HANDOFF.md`, `design/snapshots/{png,html}`, `design/snapshots/states.json`, `design/prototype/`. 아래 `§`는 ZIP 안 `HANDOFF.md`의 절 번호, `[NN]`은 스냅샷 번호.
- 원본은 화면·상호작용 설계 참고 자료. 현재 사용자 지시와 확정된 Next.js 정적 프론트·Spring Boot/Kotlin·MySQL·Spring Session JDBC·OCI Object Storage 구조가 우선. 원본의 제안 URL·SQL·기술 스택은 그대로 채택할 확정 계약이 아님. 프로토타입의 샘플 글·프로젝트·과목·계정·분석 수치·이미지와 인증/메일 흉내를 운영 데이터나 코드로 복사하지 않음. 근거: §0.3, §0.4, §5.13, §13~14.
- 상태 표기: **완료**는 현재 구현과 실제 검증 근거가 모두 있는 부분, **일부**는 하위 API/인프라만 있는 부분, **미구현**은 제품 기능이 없는 부분, **외부 조건**은 서비스 소유자의 계정·주소·비밀 설정이 필요한 부분. 새 기능의 완료 표시는 해당 화면/API/권한/실패 경로의 실제 확인 후 변경.
- 현 기준: P2-01 공통 틀·Tech 피드·기본 Markdown·로그인 화면의 정적 빌드와 격리 브라우저 검증 완료, main `fa86abc`·CI·Pages 반영 완료. 공개 Pages API는 여전히 미연결. `NEXT_PUBLIC_API_BASE_URL` 공개 HTTPS 값 미설정. Spring API의 상태 응답, MySQL 영속 저장, ADMIN/USER 로그인·로그아웃·현재 사용자·CSRF/JDBC 세션, 관리자 게시글 **초안** 5개 CRUD, 관리자 JPEG/PNG 첨부 4개 경로는 격리 환경에서 검증. P1-04A는 main `8366745` 반영 및 CI·Pages 성공. P1-04B의 출간·권한별 공개 글 조회도 main `93c2145`·CI·Pages 반영 완료. P1-04 공개 본문 캐시는 2026-09-26 격리 검증·main `2ca2169`·CI·Pages 반영 완료. P1-05A의 Tech 분류·태그·권한별 집계·필터는 main `e147f10`·CI·Pages 완료. P2-02B의 기본 편집기·편집본 관리 화면은 main `814715c`·CI·Pages 완료. 회원 관리·전체 관리 화면·검색·분석·실제 공개 API 배포 연결은 미구현. 근거: `apps/web/app`, `apps/api/src/main`, `planning/issues/P1-01.md`~`P1-04A.md`.
- 검증 방식: 기존 검사를 유지하고, 변경에 맞는 빌드·격리 HTTP/SQL·브라우저 상호작용·화면 크기별 육안/접근성 확인을 실제로 수행한 뒤 결과 기록. 원본 §15.2의 신규 자동 테스트 코드 요구는 현재 사용자 지시의 신규 테스트 중단에 종속. 실행 전 항목은 미완료.

## 데이터·권한·이동의 공통 계약

- [ ] `Post` 하나로 Tech 글·프로젝트 문서·Notes 회차를 표현하되 섹션, 요약≤120자, 본문, 공개 범위, 출간일/조회수, 태그/분류, 소속 프로젝트/과목, 순서·회차를 정합하게 저장. 대문 `Project`, 분야·과목 `Course`, 3단계 `Category`, 핀 순서, 편집 스냅샷 `Draft`, 회원·뱃지·프로필 별도 경계. 초안의 현재 `title/slug/body` 저장을 출간 완료로 표시하지 않음. 이름 변경 시 관계를 문자열 치환에 의존하지 않는 ID/FK 설계. 근거: §5.1~5.13.
- [ ] 비공개 두 단계만 사용. 방문자/열람자/관리자별 목록·검색·본문·프로젝트/과목 사이드바·태그/분류 개수·관련 글·역링크·잔디·조회 집계와 API/캐시 응답을 서버에서 필터. 비공개 프로젝트는 방문자에게 존재와 하위 제목을 노출하지 않음. 비공개 글 직접 URL과 위키 링크는 별도 안전 정책을 확정해 UI와 API 일치. 근거: §4.1~4.3, §12.8, ADR-011.
- [ ] 회원가입·중간 등급·공개 공유 링크 없음. 관리자만 발급/삭제/작성·핀·할 일 토글·분류/뱃지/프로필 관리. `USER` 현재 역할을 곧바로 열람자 완성으로 보지 않고 읽기 권한·발급/폐기 경로 검증. 삭제된 계정의 기존 세션 접근 차단. 근거: §2.2~2.3, §4, §9.19, ADR-012/019.
- [ ] URL은 정적 Next 출력 가능성에 맞게 확정하되 Home/Tech/검색/글/프로젝트/과목/로그인/쓰기/관리의 직접 새로고침·공유 링크가 같은 내용을 열도록 구성. 글 진입 경로와 무관하게 Tech는 Tech, 프로젝트 문서는 프로젝트 오른쪽, Notes 회차는 과목 오른쪽으로 이동. 좌상단 뒤로가기·섹션 전환 시 필터/문서/스크롤 초기화·편집기 나가기/출간 후 목적지 일치. §3.1의 URL 문자열은 제안. 근거: §3.1~3.3, ADR-021/022/036.
- [ ] 소분류=Tech 시리즈, 과목=Notes 시리즈. 2편 이상일 때만 `n/N`, 목록·이전/다음, 삭제/순서 변경 후 동일 번호. 핀은 섹션·필터 범위와 수동 순서. 요약은 직접 120자 또는 이미지·목록 기호를 건너뛴 자동 추출. 잔디/태그/분류/관련 글/역링크/카운트는 읽기 가능한 데이터에서 계산. 근거: §5.6~5.8/5.12, §9.1~9.11.
- [ ] 조회수는 관리자·봇·짧은 반복 방문을 제외하는 명확한 집계로 저장. 날짜와 잔디는 KST 경계, 저장·전송은 명시적 시간대. 공개 글 수정 시 캐시 무효화/장애 시 DB 조회, 비공개·관리자 데이터는 캐시 제외. 근거: §9.10/9.15, §12.11/12.13; 현재 로드맵 P1-04.
- [ ] 이미지 원본은 OCI Object Storage의 소유 prefix와 메타데이터로 관리. 관리자 첨부 API의 실제 OCI 업로드·다운로드·삭제 검증은 기존 근거이나, 공개 본문 이미지 URL/권한/만료·캡션/크기·삭제 연계는 별도 구현. 비공개 글 이미지의 직접 주소 우회 방지. 근거: §7.6, §8.6, §12.8~12.9, §13.

## Markdown 저장·읽기 수용 기준

원문 `body`를 HTML로 즉시 고정하지 않고 파서·렌더러·에디터의 왕복 계약을 먼저 확정. 현재 API는 원문 문자열을 저장/반환하고 기본 CommonMark/GFM 읽기·기본 블록 왕복 보존 일부 구현. 아래의 자체 문법·고급 기능 전체는 미완료. 근거: §7.1~7.15, §12.1, ADR-017~019/028~030.

| 항목 | 확인할 입력·출력 |
| --- | --- |
| 블록 우선순위 | fenced code → Mermaid → `$$` 수식 → 중첩 `<details>` → 표 → h1~h3 → 구분선 → 이미지 → 인용 → todo → UL/OL → 문단. 중첩 목록 비지원과 연속 문단 줄 결합 처리. §7.1/7.3 |
| 인라인 순서 | 이스케이프 `\$`, 위키 링크·주석을 강조보다 먼저, 굵게/기울임/코드/수식/일반 링크. 한국어 조사와 문장부호 경계, 중첩 인라인 비지원, 자동 링크·취소선·하드 브레이크 비지원. §7.2/7.4 |
| 접기 | `<details><summary>`의 기본 닫힘·중첩 읽기·내부 제목의 목차 제외, 에디터 재저장 시 중첩 원문 손실 없음. §7.3/7.14 |
| 표 | 헤더 구분·좌/중/우 정렬, 역슬래시+세로선 셀 이스케이프, 불균등 행 정규화, 페이지가 아닌 표 내부만 가로 스크롤. §7.5 |
| 이미지 | 캡션·`w=50`·`a=left`를 세로선으로 구분한 이미지 메타: 너비 20~100%, 정렬/캡션·안전 URL·대체 텍스트, 업로드한 OCI 객체와 메타 일치. §7.6/7.15 |
| 수식·도식·코드 | 통화 기호와 구별한 인라인 `$`/블록 `$$`, KaTeX MathML·오류 대체·`trust:false`; 실제 Mermaid strict/lazy/theme/원문 토글; 실제 Shiki 등 구문 강조·언어 표시·블록 내부 스크롤. §7.7~7.9, §12.3~12.5 |
| 할 일·주석·위키 | `- [ ]`/`- [x]`/`- [X]`, 방문자 읽기 전용·관리자 정확한 원문 항목 토글; 이름/번호 주석과 대괄호 짝; `[[제목]]`/별칭, 존재·비공개·부재 상태, 역링크와 소속 화면 이동. §7.10~7.12, §9.8~9.9 |
| 파생/왕복/보안 | 제목/본문 요약·읽기 시간·TOC 텍스트, `md → blocks → md` 재적용 고정점, 블록 기호로 시작하는 일반 문단 이스케이프. 허용 HTML은 제한적 details/summary, URL 스킴·이미지 호스트 허용 목록, XSS/이벤트 속성 차단. §7.13~7.15 |

## 알려진 프로토타입 결함 19건의 회귀 기준

기본 블록의 literal prefix·중첩 접기 원문 보존·Shift+Enter 정책 등 일부는 P2-02B에서 확인. 다음 19개 전체의 화면/섹션별 검증 완료를 의미하지 않음. 스냅샷의 외형을 따르되 다음 버그 동작은 재현하지 않음. 근거: §12.18#1~19.
