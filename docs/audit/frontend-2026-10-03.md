## 검증 결과와 한계

- 타입 검사 및 추가 `--noUnusedLocals --noUnusedParameters` 검사 통과.
- Chromium 회귀 검사 18개 통과. 390px 모바일 화면과 데스크톱을 포함하며 실제 운영 API 변경 없이 수행.
- 원고 38개의 HTML·목차·첨부·위키 결과를 파서 최적화 전 구현과 비교해 모두 일치.
- Node 검사 33개, JVM 전체 검사 42개 통과(실패·건너뜀 0개). 공개 분류·부모·revision의 MySQL 통합 검사 5개 포함.
- 파싱 호출 표본은 기본 Markdown 6→1회, 코드·표 12→2회, 접기·도식 20→5회. 첨부 수집용 전체 렌더 제거는 별도 개선.
- 최종 공개 공통 CSS 104,099바이트(gzip 29,717), 상세 CSS 37,315바이트(gzip 6,607), 폼 CSS 7,842바이트(gzip 1,982). 폼 크기는 통합한 새 분류 트리 스타일 포함. 실제 사용자 전송량·LCP·INP 개선율을 측정한 수치는 아님.
- Firefox·WebKit과 운영 데이터 부하 검사는 이번 검증에 포함하지 않음. 이미지 크기 검사는 헤더 판독이며 전체 이미지 디코딩이 아님.
- 부모 분류 표시·순서의 완전한 반영에는 API 변경 배포 후 Pages 생성 필요. 로컬 구현·테스트와 운영 반영 상태를 구분.
