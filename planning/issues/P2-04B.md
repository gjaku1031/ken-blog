# P2-04B 수식 읽기·블록 편집

## 문제와 시작 상태

수식은 현재 원문 보존만 제공. Tech 본문·표·접기의 수학 표기와 독립 수식 입력이 필요. P2-04A main `94d331d` 반영, 해당 CI/Pages 확인 뒤 구현 시작. Next 정적 Pages·Spring API·JDBC 세션 구조 유지, 공개 API 주소 미설정.

## 구현 범위

- 인라인 `$...$`와 독립 줄 `$$`로 여닫는 여러 줄 수식. 인라인 시작 뒤는 공백/달러가 아니어야 하며 닫힘은 이스케이프되지 않은 첫 달러, 닫힘 앞은 공백이 아니고 뒤는 숫자가 아닌 경우만 인정. `$A$를`은 수식, `가격은 $5와 $10`·`\$5`는 통화/문자. 코드·인라인 코드·URL·HTML·이미지 주소/대체 설명에는 수식 변환 없음. 두 달러를 같은 줄로 감싼 불명확 형식과 미닫힌 수식은 원문 유지. 인라인은 줄을 넘지 않음.
- Markdown 파서 수준에서 강조/백틱/링크보다 수식 경계가 보존되도록 처리. 읽기·한 단계/중첩 안전 접기·표 셀·편집 모델과 첨부 ID 수집이 같은 문법 사용. 수식 안의 이미지처럼 보이는 문장은 이미지 권한 선언에 포함하지 않음. 기존 raw HTML 차단·접기 검증·Markdown 원문 보존 유지.
- KaTeX는 번들에 포함하고 수식이 있을 때만 지연 로딩. `output: mathml`, `trust: false`, `throwOnError: false`, `maxExpand: 1000`, `maxSize: 10` 및 매번 새 macro 범위. 외부 CDN/이미지/링크·사용자 HTML 실행 없음. 수식 한 개 4096자/100줄 초과 시 원문 유지. 수식 블록 내부 가로 스크롤과 키보드 접근, 테마별 오류/문자 대비 유지.
- 로딩 중·실패 시 안전한 텍스트 대체 표시. 대표적인 그리스 문자·상하 첨자·분수/루트/행렬 등의 읽기 쉬운 대체를 제공하되 모르는 표현은 원문을 남김. 복잡한 TeX를 임의로 삭제하거나 모든 문법 변환을 보장하지 않음. 오류 수식은 수정 가능한 원문/오류 안내 제공. 모듈 로딩 실패는 명시적 재시도, 이전 원문/계정/경로의 늦은 결과를 다른 수식에 표시하지 않음. 전역 본문/렌더 결과 저장 없음.
- 명확한 최상위/한 단계 접기 안 수식 블록을 원문 textarea로 편집. 문단 전체 `$$`와 커서 끝 Enter로 생성, Enter는 내부 개행, Ctrl/⌘+Enter는 아래 문단, Esc는 렌더된 표현. 이동·삭제·앞뒤 블록 경계·접기 안팎 이동과 저장/재열기/출간에서 LF/CRLF·코드/기존 raw 보존. 불명확한 수식/중첩 구조는 편집 가능한 것으로 오인하지 않음.
- 한국어 JSDoc, 필요한 최소 의존성 고정·문서 갱신. 신규 저장소 테스트·학습 문서 없음.
