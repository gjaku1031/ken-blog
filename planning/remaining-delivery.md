## 실제 연결과 별도 설정

- 최신 요청으로 Tailscale HTTPS 공개 주소 사용 및 새 전용 DB·OCI Object Storage·Redis Cloud 연결 진행. 실제 결과는 [운영 연결 기록](issues/CONNECTION-2026-09-27.md) 기준.
- 이메일 기능 전면 제외. 아이디·비밀번호 로그인과 직접 초대 링크 사용. 메일 제공자·발송 권한 불필요.
- GA 공개 측정 ID는 `G-JDYNG61J70`. Data API의 속성 ID와 서비스계정 읽기 권한은 별도이며 측정 ID로 대체 불가. 실제 통계 미연결 시 샘플 수치 없음.
- 운영 비밀값은 저장소 밖 전용 파일, CI는 임시 DB 사용. GitHub 공개 API 변수에는 HTTPS 주소만 저장.
