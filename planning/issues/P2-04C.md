# P2-04C Mermaid 도식 읽기·블록 편집

## 문제와 시작 상태

코드·수식은 읽기와 편집을 제공하지만 Mermaid fence는 원문 보존만 제공. 도식의 관계를 실제 배치한 읽기 화면과 원문 편집 필요. P2-04B main `d4d291d` 반영, CI/Pages 성공 확인 뒤 구현 시작. Next 정적 Pages·Spring API·MySQL 세션·OCI 계약 유지.

## 구현 범위

- 명확한 `mermaid` fence를 도식 블록으로 구분하고 실제 Mermaid 라이브러리로 렌더. 최소 flowchart·sequence·class·state·ER 자료 검증. 미지원/불명확 문법은 원문 보존. fenced 원문·LF/CRLF·들여쓰기·종료 fence와 다른 블록의 무수정 왕복 보존.
- 카드 머리의 도식 종류와 소스 보기/다이어그램 보기 전환. 원문은 React 텍스트로 표시. 다이어그램이 있는 화면에서만 라이브러리 지연 로딩, 로딩·실패/구문 오류에서 원문 유지 및 명시적 재시도. 네트워크 연결을 복구한 재시도로 정상 표시 가능.
- strict 보안·자동 실행 해제·HTML label 해제, 페이지 테마에 맞는 렌더 설정. 사용자 directive/frontmatter로 보안·테마·CSS 설정 덮어쓰기 금지. 클릭 실행·외부 링크/이미지·사용자 HTML/CSS·외부 폰트/아이콘·CDN 요청 차단. 출력 SVG도 검증/정제하고 이벤트 바인딩 없음. 외부 자원을 포함한 도식은 소스와 지원 범위 안내로 대체. 단순 strict 설정만으로 모든 외부 요청이 차단된 것으로 간주하지 않음.
- 동일 페이지 여러 도식과 테마 변경 시 설정/ID 충돌 방지. 렌더 대기열에서 이미 떠난 화면의 작업 건너뛰기, 완료 결과는 원문·테마·현재 경로와 일치할 때만 표시. 비공개 원문/결과의 전역 캐시 없음. 렌더 비용 상한은 원문 길이/줄 수 및 라이브러리의 노드/선 제한으로 명시하고 초과 시 원문 유지.
- 관리자 문단 전체의 ` ```mermaid `와 끝 커서 Enter로 생성. textarea 원문 편집, Enter 개행·Ctrl/⌘+Enter 아래 문단·Esc 미리보기. 코드 언어 변경과 Mermaid 변환 경계 명시. 이동·명시적 삭제·한 단계 접기 안팎 이동, 저장/재열기/출간에서 원문 유지. 수식/코드 안의 이미지 모양 텍스트와 동일하게 첨부 ID 수집 대상에서 제외.
- 긴 도식은 도식 카드 내부 스크롤, 좁은 화면에서 페이지 넘침 없음. 제목/소스 토글의 접근 가능한 이름·키보드 초점·대체 원문·양 테마 대비 확인. 한국어 JSDoc 및 기능 문서 갱신.
