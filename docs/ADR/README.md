# 아키텍처 결정 기록

현재 설계와 그 이유를 보관하는 원본 문서. 관련 구현을 바꿀 때 해당 ADR의 결정·영향·검증 상태도 함께 갱신.

| 변경 영역 | 먼저 읽을 문서 |
| --- | --- |
| 글·시리즈·Markdown·관리자 인증·제거된 기능 | [애플리케이션 구조](ADR_application.md) |
| JPA·jOOQ·엔티티·스키마·코드 생성 | [영속성과 코드 생성](ADR_persistence.md) |
| 공개 탐색·관리자 상태·브라우저 렌더링·검증 | [프론트엔드](ADR_frontend.md) |
| Pages·Caddy·JVM·CI·배포·성능 | [인프라](ADR_infra.md) |

ADR에는 결정·배경·대안·영향과 실제 검증 결과를 기록하고, 구현 완료와 운영 적용을 구분. 이전 결정은 폐기 또는 대체 사실을 표시하여 현재 규칙과 혼동하지 않는 기준. 임시 TODO·대화 이력·로컬 경로·자격 증명은 ADR에 포함하지 않음.
