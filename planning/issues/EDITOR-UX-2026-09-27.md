# 글쓰기 선택·주석·이동 UX 보정

## 문제와 범위

- 투명한 네이티브 프로젝트 select로 운영체제 메뉴 노출. 사이트 테마 팝오버·키보드 선택·프로젝트 추가 페이지 조회로 교체.
- 자식이 없는 분류의 펼침 조건 누락으로 중/소분류 추가 동작 접근 불가. 3깊이 제한 내 생성·자동 선택 복원.
- 주석 입력마다 deferred 모델 불일치 시 미리보기 목록 제거/재생성. 이미 확인된 목록 유지 및 최신 내용 교체.
- 블록 단일 이동의 대상 표시 부족. 삽입선·이동 강조·동일 편집기 내 다중 선택/이동 추가. 이미지 파일 drop의 삽입 위치 표시 포함.
- 이미지 정렬 아이콘의 방향 불명확. 좌/중/우 SVG·선택 상태·위치 변경 효과 및 작은 화면 도구 접근 보정.
- 추가 확정: 선택한 줄에는 입력 문법을 표시하고 다른 줄에는 미리보기 유지. 제목 `#` 표시·크기 유지·단계 변경/해제와 커서·주석 삽입 좌표 일치 포함.
- 추가 요청: 사용자 직접 QA를 위한 운영 DB 목업 대량 생성·유지. `[QA]` 이름·`qa-20260927-*` 주소·별도 QA 분류 및 생성 ID 목록으로 기존 데이터와 구별. 사용자 QA 종료 요청 전 삭제 금지. 이번 변경의 소수 기능 검증용 `editor-ux-check-*` 자료는 별도 ID 목록으로 정리.

## 수용 기준

- 프로젝트 없음/선택/해제·키보드·추가 페이지·모바일 테마 표시 및 임시저장 복원 확인.
- 빈 대분류→중분류→소분류 생성 및 정확한 ID 선택, 4깊이 생성 미노출 확인.
- 주석 직접 입력·도구 삽입 중 포커스 유지, 미리보기 제거 반복 없음, 내용 갱신 확인.
- 단일/범위/개별 블록 선택·드래그 위치·키보드 이동·취소 시 순서와 본문 보존 확인.
- 이미지 정렬·폭·외부 파일 drop·기존 이미지 이동·reduced-motion·모바일 가로 넘침 확인.
- 활성 제목 문법·Enter 분할·Backspace·주석 삽입·본문 원문 저장 보존 확인.
- 신규 테스트 소스 없이 기존 웹 검사·타입 검사·정적 빌드 수행. 관련 코드만 main 반영 후 CI/Pages 및 실제 배포 확인.
- 검증용 ID만 추적/정리. 사용자 java/spring 및 작업 중 원고 보존. API 애플리케이션 계약·외부 비밀 설정 변경 없음. 대량 QA 입력 중 실제 OOM 확인으로 전용 API 컨테이너 메모리 1GiB·JVM 힙 비율 50% 보정 포함.
