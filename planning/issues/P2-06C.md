# P2-06C 글 사이 탐색 — 링크 선택기·역링크·목차

## 문제와 기준 상태

P2-06B main `a6f8a6e` 위키 읽기·권한·실패 복구 구현과 CI36240322404·Pages36240322370 성공. 현재는 제목을 직접 입력해야 하고 참조하는 다른 글이나 본문 제목으로 이동할 탐색 수단이 없음. 세 기능을 하나의 사용자 흐름으로 묶어 구현·통합 검증·반영.

## 구현 범위

### 관리자 링크 선택기

- 관리자 GET `/api/v1/admin/posts/title-search?q=...`: 1~200 codepoints의 검색어, 제어문자/개행 금지, 제목 부분 일치 출간 글 최대7개. 본문 조회 없음. 같은 제목은 위키 resolve와 같은 최초 출간 canonical 한 건으로 통일하고 결과는 canonical 출간 시각 최신순. `%`/`_`를 와일드카드로 취급하지 않음. 응답 `{items:[{id,title,slug}],exact:WikiLinkResult}`에서 exact는 입력 제목의 현재 해석 결과. ADMIN·인증 origin·no-store 유지.
- 글쓰기 하단 `글 링크` 팝오버: 검색·대기·빈 결과·오류, ↑↓ 선택/Enter 확정/Esc 닫기, 열기 전 커서·선택 범위 보존, `[[제목]]` 삽입 후 초점 복구. IME와 접기 자식 삽입, 원문 보존. 위키 제목에 허용되지 않는 문자는 삽입하지 않음. 없는 유효 제목은 선택하여 빨간 링크로 작성 가능. 프로젝트 추천은 해당 모델 구현 뒤 추가.
- 읽기에서 ADMIN만 MISSING 링크를 클릭해 `/write/?title=...`의 새 Tech 초안을 시작. 기존 다른 쿼리와 혼합 불가, 길이·형식 검증, 기존 편집본 덮어쓰기 없음.

### 저장된 참조와 역링크

- 서버에서 또 다른 Markdown 파서를 만들거나 매 요청마다 전체 본문을 읽지 않음. 기존 공유 프론트 파서가 추출한 최대128개 `wikiTargets`를 관리자 본문 저장 DTO의 명시적 연결 메타데이터로 전달. Spring은 관리자 권한·제목 형식/길이·개수·트랜잭션·본문 버전과 공개 범위를 검증. 이는 첨부 ID와 유사한 작성자의 연결 선언이며, 서버가 Markdown 의미를 재분석했다는 계약은 아님.
- Flyway로 게시글/편집본의 제목 참조 테이블 생성. JpaRepository·FK cascade·한 글 내부 중복 제거. 저장·편집본 출간과 같은 트랜잭션에서 전체 교체. 편집본 생성 시 원문 연결 복사, 편집본 저장은 공개 원문 인덱스와 분리, 출간 때만 공개 글에 반영.
- 기존 API 클라이언트의 생략/null은 새 글에서 빈 연결. 본문 변경 시 선언이 생략되면 기존 연결을 지워 오래된 역링크 방지, 본문이 같으면 기존 연결 유지. 제목/공개 범위 변경은 조회 시 현재 값으로 판정. 관리자 상세에는 실제 저장된 `wikiTargets` 제공. 새 편집기는 매 저장마다 현재 원문에서 계산한 전체 목록 전송.
- GET `/api/v1/posts/{slug}/backlinks?page=0`: 현재 읽을 수 있는 출간 대상만, 현재 canonical 대상이 아닐 때 빈 결과. 읽을 수 있는 출간 출처만, 자기 자신 제외·중복 제거·최신 출간순, 한 페이지10개와 `hasMore`. `{items:[{id,title,slug}],page,hasMore}`. 본문·비공개 건수·초안 메타데이터 제외. PRIVATE 대상의 익명 요청은404, no-store와 기존 GET origin별 CORS 유지.
- 기존 글 보정용 관리자 PUT `/api/v1/admin/posts/{id}/wiki-links`: `{expectedBodySha256,wikiTargets}`로 부모 행 잠금 아래 현재 본문 SHA와 비교해 연결만 교체, 불일치409. 본문/updatedAt 수정 없음. 이 API로 공유 파서를 실행하는 일회성 Node 도구 제공. 기본 dry-run, `--apply`에만 반영, 비밀값·본문 출력 금지. 변경된 본문은409로 건너뛰어 재실행하도록 안내. 기존글 자동 보정 완료를 가정하지 않음. 실제 운영 DB에 실행하지 않음.
- 읽기 하단 `이 글을 가리키는 글`: 로딩/오류/재시도·더 보기·빈 목록 숨김. 세션/경로 변경 시 결과 폐기. 예전 API로 작성한 글은 보정 또는 새 편집기로 재저장하기 전까지 연결 없음이라는 운영 한계 명시.

### 본문 목차

- 기존 안전 파싱 결과의 h2/h3에서 제목·안정적인 앵커 추출. 접기 내부 제외, 제목 문자열 기반 ID와 중복 suffix, 위키 표시명·주석 제외 등 읽을 수 있는 텍스트로 표시. 관계없는 앞 문단 추가로 앵커 변경 없음.
- 데스크톱 오른쪽 sticky 목차, 모바일 본문 뒤 배치. 클릭/키보드 이동과 헤더 여백·reduced motion, 현재 제목 scrollspy. 문서/세션 교체 때 observer와 스크롤 상태 정리. 제목이 없으면 숨김.
