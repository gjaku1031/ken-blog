권한은 화면이 아니라 서버가 요청마다 확인하고, 응답은 기본적으로 저장되지 않게 내보냄.

## 신뢰 경계

방문자가 사이트로 들어오는 길은 Cloudflare 터널 하나임. 웹은 서버 안의 주소에만 열려 있고, API 컨테이너는 서버 안에서도 포트를 내놓지 않아 웹을 거쳐야 닿음. 배포는 SSH로 함. PostgreSQL은 서버 안의 주소에만 열려 있음.

## 인증과 세션

| 항목 | 설계 |
| --- | --- |
| 가입 | 아이디와 비밀번호, 필수 약관 동의. 이메일을 받지 않아 자동 비밀번호 찾기는 없음 |
| 비밀번호 | Argon2id로 해시해 저장 |
| 세션 | PostgreSQL에 저장(Spring Session JDBC). API를 다시 시작해도 로그인이 유지됨 |
| 세션 쿠키 | HttpOnly, SameSite=Lax, HTTPS에서는 Secure |
| 사용자 확인 | 요청마다 사용자를 DB에서 다시 읽음. 계정 삭제와 권한 변경, 댓글 제한이 다음 요청부터 적용됨 |
| 시도 제한 | 가입과 로그인을 IP 단위로, 로그인은 IP와 아이디의 조합 단위로도 제한 |

## 권한

`/api/admin` 아래의 경로는 처리하는 코드에 표시가 있든 없든 운영자만 부를 수 있음. 경로는 요청을 처리할 코드를 찾을 때와 같은 기준으로 나눠서 판단함. 주소 문자열을 그대로 비교하면 `/api/admin;x/orders`나 `/api/%61dmin/orders`처럼 처리 코드는 찾아가지만 문자열 비교는 빗나가는 요청이 검사를 피하기 때문임.

편집 모드는 화면에 단추를 보이는 상태일 뿐이고 권한과 무관함. 고객의 주문은 본인의 것인지 서버가 확인함.
