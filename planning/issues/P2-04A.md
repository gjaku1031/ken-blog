# P2-04A 코드 블록 구문 강조·언어 편집

## 문제와 현재 상태

기본 fenced code의 원문 저장·편집은 있으나 읽기와 편집 종료 화면에 실제 구문 강조·언어 표시 없음. P2-03B 이미지 기능 main `ea3a948` 반영, 해당 CI/Pages 확인 뒤 구현 시작. 공개 API 도메인·HTTPS 미설정 상태와 기존 VM 배포 유지.

## 구현 범위

- Shiki의 실제 문법 분석으로 코드 강조. 정적 Pages와 브라우저 API 본문에 맞춰 코드가 있는 화면에서만 로더 실행. core·JavaScript regex engine·고정된 언어/테마 import 사용, CDN·임의 사용자 경로 import 없음. 지원 언어 Kotlin/Java/JavaScript/TypeScript/JSON/SQL/Bash/YAML/Python/CSS/HTML/Markdown와 통상 별칭 명시. 알 수 없는 언어와 과대한 입력은 언어 라벨과 원문 유지.
- 결과는 Shiki 토큰의 문자열/색을 React 노드로 표시. 사용자 원문 HTML 삽입·실행 없음. 읽기·표/접기 안 코드·편집 종료 미리보기에 같은 컴포넌트 사용. 인라인 코드는 기존 표현 유지. 긴 줄은 코드 내부 가로 스크롤, 키보드 초점과 언어 라벨 제공. 기본 원문이 항상 먼저 보이며 로딩 실패로 원문이 사라지지 않음.
- 지원 언어별 지연 로딩과 공통 highlighter 재사용, 생성/언어 로딩 실패는 재시도 가능. 비공개 본문이나 토큰을 전역 영구 캐시에 저장하지 않음. 컴포넌트 변경/해제 시 늦은 토큰 결과 무시, 옛 본문이 새 원문 위에 나타나지 않음. 동작 비용 제한을 위해 최대 20,000자/500줄까지만 강조하며 초과 원문 그대로 표시.
- 코드 편집 중 강조 없는 textarea 유지, 언어 변경 입력·Esc 미리보기·Enter 줄바꿈·Ctrl/⌘+Enter 아래 문단. 코드 펜스 명령은 문단 전체와 커서 끝에서만 확정. 저장 후 LF/CRLF와 코드 안 백틱·틸드·HTML·주석·할 일·attachment 문자열 보존. 지원하지 않는 펜스 메타는 기존 raw 보존.
- 실제 사용 중인 언어값은 원문 보존, 입력 변경 시 제한된 언어 문자열 검증. Mermaid를 일반 코드 언어로 바꾸는 UI 없음. Mermaid 도식·수식은 별도 단계.
- 한국어 JSDoc, README·Markdown/편집 안내와 현재 계획 갱신. 신규 저장소 테스트·학습 문서 없음.

## 제외 범위

수식·Mermaid 실제 렌더, 위키·주석, 코드 실행/온라인 컴파일·CDN 호출·클립보드 복사 버튼 추가 없음. 백엔드/DB/OCI/API 권한 계약 변경 없음. 기존 운영 컨테이너·외부 비밀 설정 변경 없음.
