## 구현 범위

- `[[제목]]`과 `[[제목|표시명]]`을 안전한 인라인 요소로 해석. 대상 제목 앞뒤 공백 제거,1~200 Unicode codepoints와 제어문자·개행·대괄호·세로줄 금지. 표시명은 비어 있지 않은 한 줄 일반 텍스트로 표시하며 HTML/Markdown 재실행 없음. 잘못 닫힘·중첩·이스케이프·길이 초과는 저장 원문 보존, 화면에서는 기존 Markdown 규칙 적용. 본문 최대1MiB와 파싱 구간당 위키 후보 검사 최대512개 등 유한한 파싱/네트워크 비용 명시.
- 일반 텍스트·제목·목록·인용·표·허용된 접기 본문과 주석 내용에서 동일한 규칙 적용. 코드/수식/Mermaid·이미지·이미지 대체문자·기존 Markdown 링크 라벨/주소·raw HTML에서는 해석하지 않음. 주석 및 접기 재파싱 뒤에도 위치·원문·검증된 노드 경계 유지. 주석 말풍선 안에서는 이동 비활성, 하단 주석에서는 허용된 링크 이동.
- 문서 단위 중복 제목을 모아 기존 API로 배치 조회. 각 요청20개·합계1500 UTF-8bytes·인코딩6144bytes 한도, 전체 고유 제목 상한128개·동시요청2개 이하. 초과 구문은 원문/미확인 상태로 남기며 잘못된 MISSING으로 표시하지 않음. 전체본문/개인정보를 요청에 싣지 않음.
- READABLE은 API 응답의 엄격히 검증된 slug를 기존 `/post/?slug=` 경로로 연결. LOCKED는 회색 점선·이동 불가, MISSING은 빨간 점선·일반 사용자는 이동 불가. 조회 중·설정 없음·네트워크/서버/응답 오류는 별도 미확인 상태로 표시하며 없는 글로 오인하지 않음. 오류 시 명시적 재시도 제공, 무한 자동재요청 없음.
- 세션 epoch·문서/route/body 변경 시 결과와 요청 폐기. 기존 auth.readCredentials·401 만료 흐름 재사용, 로그인·로그아웃 후 PRIVATE 메타데이터 잔존 방지. 캐시·로컬 저장소 없음. 본문 단위로 요청하며 링크 요소마다 개별 fetch 없음.
