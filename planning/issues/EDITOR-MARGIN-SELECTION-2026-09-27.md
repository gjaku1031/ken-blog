# 편집기 바깥 여백의 블록 선택

## 문제와 범위

- 블록 편집기 내부와 좁은 왼쪽 여백에서만 마퀴 시작 가능, 본문 중간 블록을 넓은 좌우 여백에서 선택하기 어려운 문제.
- 본문 높이에 대응하는 페이지 좌우 빈 공간에서 수직 드래그로 최상위 블록 범위 선택. 기존 드래그 손잡이·키보드 이동과 본문 텍스트 선택 유지.
- 제목·프로젝트 설정·헤더·도구막대·대화상자·입력 컨트롤 제외. 터치 스크롤 보존, 말미 화면 전용 문단 제외.
- 운영 원고·DB 변경 없음.

## 수용 기준

- 좌우 여백에서 중간 블록 한 개·여러 개, 위아래 방향 선택. 바깥 여백 안에서만 수직으로 움직여도 선택 가능.
- 선택 직후 빈 여백 클릭으로 해제, 손잡이·Alt 방향키로 선택 묶음 이동.
- 긴 본문에서 가장자리 자동 스크롤, Escape·포인터 취소·화면 이탈 정리.
- 본문 편집·글자 선택·프로젝트 설정·검색·도움말·출간 창의 기존 상호작용 유지.
- 변경 범위 타입·기존 검사·정적 빌드 및 데스크톱·모바일 실제 브라우저 확인. 신규 저장소 테스트 없음.

## 진행

- 기존 루트 편집기 pointerdown 범위 제한 및 사각형의 가로 교차 조건 확인.
- 최상위 편집기에서 문서의 pointerdown을 받아 페이지·작성 영역 자체의 좌우 빈 배경만 허용. 본문 높이 밖이나 입력·버튼·손잡이 타깃은 제외.
- 5px 이상 드래그 시 가로 교차 없이 블록과 세로 범위 비교. 선택 박스는 본문 폭에 표시, 기존 내부 선택·자동 스크롤·선택 해제 흐름 공유.

## 검증

- 웹 타입 검사·기존 검사 7개·정적 17경로 빌드·diff 검사 통과. 저장소 테스트 추가 및 API 변경 없음.
- 1232px에서 좌우 여백의 정방향·역방향 드래그로 중간 4개 블록 정확히 선택, 블록 1개·대각선 드래그·Alt+방향키 선택 묶음 이동 확인.
- 위아래 자동 스크롤, 말미 가상 문단 제외, 빈 여백 클릭 해제·Escape·진행 중 창 blur 정리 확인.
- 프로젝트 설정 위쪽 여백 드래그는 선택 없음, 제목 입력·도움말·본문 textarea의 실제 글자 선택 유지 확인.
- 390px 가로 넘침 없음, 네이티브 터치 스크롤이 블록 선택을 시작하지 않음 확인. 브라우저 런타임 오류 없음. 모든 편집 입력 미저장 폐기, 운영 원고 변경 없음.
- 초기 검증의 폰트 적용 전 좌표 수집과 CDP 직접 생성 텍스트 드래그 문제를 검증 도구에서 보정, 최종 브라우저 검사 통과. 제품 실패와 구별.
- 전달 SHA의 원격 CI·Pages 및 실제 배포 화면 확인 결과는 로컬 인계 기록 대상.
