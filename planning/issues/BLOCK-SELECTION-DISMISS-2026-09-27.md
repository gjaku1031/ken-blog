# 빈 여백 클릭의 블록 선택 해제

## 요청·수용 기준

- 선택 블록이 남아 있는 상태에서 빈 공간 클릭 시 위치에 관계없이 선택 해제.
- 본문 좌우·블록 사이·이미지 주변·편집 캔버스 외부·하단 여백 포함.
- 실제 텍스트 편집·이미지 설정·손잡이 다중 선택·박스 선택·그룹 이동·중첩 접기 상호작용 유지.
- 선택 해제로 원고 추가·변경·저장 발생 없음. 선택 안내 영역 제거로 클릭 대상이 바뀌는 오작동 방지.
- 한국어 주석·기존 검사 유지, 신규 저장소 테스트 없음. API·운영 콘텐츠 변경 없음.

## 원인·검증

- 기존 마우스 박스 선택 경로에서 임계 이동 없는 클릭을 해제 동작으로 처리하지 않으며, 에디터 밖 여백과 이미지 프레임 여백이 이벤트 대상에서 누락된 코드 확인.
- 실제 Pages에서 본문 좌우·상단·하단 여백을 클릭해도 선택 1개가 유지되는 문제 재현.
- 선택 상태가 있는 동안 문서 포인터 클릭 경로를 연결하고, 클릭과 4px 이상 이동하는 드래그 구별. 이미지 양옆과 편집기 밖 여백 포함. 실제 이미지·입력·선택 손잡이·이동 버튼은 기존 동작 유지.
- 하단 빈 영역에서는 선택 해제만 수행해 마지막 문단의 불필요한 활성화 방지. 텍스트 미리보기 클릭은 의도한 문단 편집과 선택 해제 병행.
- 모바일 터치의 호환 클릭보다 먼저 만료되는 후보 상태 보정. pointerup 이후 최대 1.2초 유지, 클릭 위치·드래그 이동·취소·창 blur 재확인. 다음 이벤트 작업에서 표시 제거, 요소 blur와 창 blur 구분.
- 웹 타입·기존 7개 검사·최종 정적 20경로 빌드·diff 검사 통과. 로컬 Chromium 데스크톱과 390px 네이티브 터치 38항목 통과: 좌우/상단/하단/이미지 여백 해제, 문단 편집 대상 유지, 박스 선택·삽입선·그룹 드래그·화살표 이동·이미지 정렬·중첩 선택 보존. 런타임 오류·가로 넘침·쓰기 요청 없음.
- 검증 좌표가 문단 사이가 아닌 다음 미리보기 버튼을 가리키는 경우와 고정 하단 도구가 중첩 손잡이를 가린 경우를 검증 도구에서 보정. 제품 결함과 구분.
- main·CI·실제 Pages 최종 배포 후 같은 브라우저 검증 예정.
- 검증 원고는 실제 조회 응답의 브라우저 내부 복사본에만 적용. GET/HEAD 외 호출 차단, 사용자 글·임시저장·첨부 변경 없음. 저장소 외 검증 자료 `/tmp/ken-blog-block-dismiss`.
