# 단일 관리자와 OTP 로그인

## 요청·범위

- 회원·초대 기능 제거, 단일 관리자 계정만 로그인 허용. 비공개 글은 관리자 전용으로 전환.
- 기존 비밀번호와 Google Authenticator TOTP 또는 일회용 복구 코드 모두 확인한 뒤 JDBC 인증 세션 발급.
- 사용자 요청으로 복구 코드 원문은 로컬 레포의 Git 제외 디렉터리 `.local-security/`에 0600 보관. 일반 문서·정적 산출물·로그에 원문 포함 없음.
- 기존 글·프로젝트·과목·첨부·QA 자료 보존. 이전 로그인 세션과 일반 회원 세션의 우회 차단.
- 이메일·JWT·Redis 세션 도입 없음. 기존 Spring Security·Spring Session JDBC·MySQL 유지.

## 수용 기준

- 회원 관리 메뉴·페이지·초대 페이지·HTTP 계약·구현 제거. 모든 공개/비공개 읽기 경로에서 관리자 전용 정책 일치.
- 비밀번호만 제출, 잘못된 OTP, 만료·재사용 OTP, 다른 계정, 이전 인증 세션의 관리자·비공개 접근 거부.
- TOTP 6자리·30초·SHA1·허용 시간 오차 제한, 마지막 사용 시간 구간 저장 및 동시 사용 방지.
- 복구 코드 해시만 서버 DB에 저장, 동시 요청 중 한 번만 소비. 재시작 후 소비 상태 유지.
- 인증 실패 횟수 및 짧은 잠금 유지, 설정 누락 시 비밀번호 단독 로그인으로 우회 없음.
- 복구 원문·등록 QR은 로컬 전용, 설정 비밀값은 서버 전용 환경 파일. Git 제외·권한 검사.
- 신규 저장소 테스트 없음. 기존 검사와 격리 HTTP·실제 브라우저·운영 연결 검증 수행.

## 검증 기록

- 기존 비밀번호 단독 로그인·일반 회원 PRIVATE 열람·회원/초대 화면 및 API 연결 확인.
- 회원·초대 웹 경로·메뉴·컴포넌트·API·일회용 초대 테이블 제거. 과거 계정 행·콘텐츠는 보존하고 설정된 ADMIN 한 명만 로그인 허용.
- TOTP SHA1·6자리·30초·현재 구간 전후 1개 허용. DB 단일 행 잠금으로 최신 성공 구간·복구 코드 소비·실패 횟수 직렬화. 실패 5회 후 60초 잠금, 잠금 중 요청에 의한 만료 연장 없음.
- 설정 지문·증가형 버전·계정 암호 해시를 세션 검증에 사용. 기존 비밀번호 전용 세션 차단, 설정 변경 및 원복 후 이전 세션 재활성화 차단. 설정 누락 시 로그인 거부, 공개 건강 검사 유지.
- 최종 API clean verify 기존 28개, 웹 타입 검사·기존 7개·정적 빌드·diff 검사 통과. 새 테스트 파일 추가 없음. 기존 Flyway 기대값 V22와 인증 요청 계약만 조정.
- 격리 HTTP 15개 검증 묶음 통과: V22 데이터 보존, 이전 세션·다른 계정·잘못된 코드 거부, CSRF·CORS·세션 교체, 비공개 본문 경계, 동시 코드 사용, 복구 코드 정규화·1회 소비, 재시작·잠금 만료·설정 회전·설정 누락·계정 변경·로그아웃.
- 실제 브라우저의 TOTP 및 복구 로그인, 코드 앞자리 0 유지·모드 전환 시 입력 폐기·실패 메시지·관리 메뉴·390px 가로 넘침 없음 확인. 검증 도구의 비표준 선택자만 보정 후 로그아웃 재확인, 제품 오류 없음.
- 복구 코드 10개·등록 QR의 0600, 디렉터리 0700, Git 제외 확인. 추적 소스·정적 산출물의 운영 비밀값 미포함 확인. 운영용 복구 코드는 검증에 소비하지 않음.
- 운영 전 전용 MySQL 스키마 압축 백업과 계정·글·프로젝트·과목·첨부·편집본 스냅샷 보관. 운영 API 배포 후 공인 HTTPS health UP·OOM false·재시작 0 확인. 실제 비밀번호 단독 로그인 401, TOTP 로그인·기존 세션 차단·회원 경로 404·GA4 READY 확인. 기존 데이터 비교에서 글 조회수 자연 증가 1건 외 계정·콘텐츠 변경 없음, 운영 복구 코드 10개 미사용 확인. Pages 최종 반영 확인 대상.
