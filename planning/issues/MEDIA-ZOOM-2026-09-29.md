# 본문 이미지·Mermaid 확대 보기

## 요청과 범위

- 본문 이미지와 Mermaid 도식에 돋보기 버튼 추가, 작은 글씨와 관계를 넓은 화면에서 읽는 기능
- 공통 확대 창에서 화면 맞춤·확대/축소·스크롤 탐색·닫기 지원
- 첨부 권한 확인을 거친 기존 blob과 검증된 Mermaid SVG만 재사용, 원고·첨부 원본·API·DB 변경 제외
- 이미지 정렬·캡션·편집 제어, Mermaid 원문 보기·실패 안내 유지

## 수용 기준

- 준비된 본문 이미지와 단순/일반 Mermaid 모두 확대 가능
- 데스크톱·모바일·라이트/다크에서 화면 맞춤 및 확대 부분 탐색 가능, 본문 가로 넘침 없음
- 닫기 버튼·Escape·배경 클릭·키보드 포커스 복귀 및 배경 스크롤 잠금 정상
- 계정/원문/경로/테마 교체 및 컴포넌트 종료 시 이전 확대 내용과 임시 URL 수명 보존
- 로딩·권한 거부·실패 상태에서 깨진 확대 화면 없음, 원문 및 편집 동작 보존
- 기존 웹 검사·타입·정적 빌드, 격리/실제 브라우저 및 동일 SHA CI·Pages 확인

## 구현과 로컬 검증 — 2026-09-29

- 첨부 이미지 우측 하단 돋보기, Mermaid 머리글 확대 버튼 및 공통 모달 구현 완료
- 원본 이미지·검사된 SVG 재사용, 단순 흐름도도 같은 확대 창 지원. SVG 두 축 비율 유지, 화면 맞춤·확대/축소·스크롤 탐색 지원
- native dialog 초점 제한, Escape·배경·닫기 버튼, 호출 버튼 초점 복귀와 배경 스크롤 복원 확인
- 요청·계정·경로·테마·원문 변경 시 확대 상태 초기화, 이전 테마 복귀 시 자동 재개 방지 확인
- 기존 웹 검사 7개·타입 검사·최종 정적 빌드 29경로 및 예약 경로 3개 제거·공개 스냅샷 검사·변경 형식 검사 통과. 신규 저장소 테스트 추가 없음
- 실제 공개 Vowser 이미지 3개와 도식, 격리 단순 흐름도·시퀀스·깨진 이미지·잘못된 도식 확인. 준비되지 않은 매체의 확대 버튼 없음, Mermaid 소스 보기 유지
- 1082px 라이트·390px 다크, 화면 맞춤·배율 조절·확대 영역 스크롤·모바일 터치·Tab·Escape·배경 클릭 확인. 가로 넘침 및 브라우저 실행 오류 없음
- 확대 시 추가 첨부 요청 없음, 같은 권한 확인 blob 재사용 확인. 페이지 이동과 테마 왕복 시 모달 및 배경 잠금 해제 확인
- 공개 읽기와 브라우저 전용 임시 데이터로 검증, 운영 콘텐츠·첨부·API·DB 쓰기 없음
