# 공통 화면 폭·분류 순서 QA 반영

## 요청과 범위

- 본문 외 홈·글 목록 등 기존 공통 폭 그룹에도 52px 확대 적용. 기본 1040→1092, 넓은 화면 1152→1204, 편집 캔버스 760→812. 이미 확대한 글 상세 1132 유지.
- 분류 관리에서 같은 부모를 가진 대·중·소분류의 드래그 순서 변경·영속 저장. 부모나 글 소속 변경 없음.
- 홈·Tech·검색·글쓰기·관리의 분류 순서 일치. 기존 순서 보존과 신규 분류 마지막 배치.
- GA4 미연결 원인 확인. 운영 응답 UNCONFIGURED, 숫자 속성 ID와 서비스 계정 인증 설정 모두 없음. Pages 수집 활성 변수도 미설정. 제공된 측정 ID만으로 보고서 조회 불가.
- 공통 Home·Tech·검색 카드의 Tech 연관 프로젝트를 메타 다음·제목 앞 별도 줄로 표시. `[연관 프로젝트]`만 테마 초록색, 프로젝트명 일반 메타 색상.
- 사용자 글·QA 자료 보존. 새 테스트 파일·사용자 설명 문서 작성 없음.

## 수용 기준

- 공통 CSS 변수의 최대 폭을 사용하고 좁은 화면의 기존 여백·가로 넘침 방지 유지.
- 삽입 위치·드래그 대상 표시와 저장 중 잠금, 실패 안내. 키보드와 모바일 대체 조작 가능.
- 순서 API의 중복·누락·다른 부모·권한 검증, 저장 후 새 조회와 공개 분류 순서 일치.
- 기존 데이터 순서를 유지하는 마이그레이션과 격리 HTTP 검증, 변경 범위의 빌드·기존 검사·브라우저 확인.

## 검증

- API clean verify 기존 28개·웹 타입검사·기존 7개·정적 20경로 빌드·diff 검사 통과. 신규 저장소 테스트 없음.
- 격리 MySQL V20→V21에서 기존 분류 ID/부모/경로/이름/순서 보존 확인. 대·중·소분류 순서 PUT/새 조회/공개 트리 일치, 생성 마지막 배치, 누락·중복·다른 부모·없는 부모·CSRF·회원 권한 거부, 동시 생성과 순서 변경 보존 확인.
- 정적 브라우저에서 Home/Tech/Projects/Notes/Search/Admin/Write 데스크톱 폭과 390px 가로 넘침 없음 확인. 분류 실제 native drag·삽입선·ghost, 반복 Alt 방향키·포커스 복원, 저장 중 잠금, 모의 409 복원, 새로고침 순서 유지, CDP 실제 터치 버튼 이동, 공개/편집 분류 순서 일치, 런타임 오류 없음 확인.
- 브라우저 도구의 소수 좌표·JSON 공백 비교·이동 애니메이션 직후 클릭 대기 문제는 검증 도구 수정 후 통과. 제품 오류로 기록하지 않음.
- 운영 전용 스키마의 저장소 밖 0600 압축 백업 후 API 이미지 배포. V21·공인 HTTPS health UP·기존 분류/게시글/분류 표시 순서 불변 확인. 새 빈 임시 분류만 별도 생성해 운영 순서 저장 검증, Pages 확인 후 해당 ID만 정리 예정.
- GA 운영 응답 UNCONFIGURED/metrics null 유지. 사용자 속성 ID·서비스 계정 아직 없음 확인, 공식 준비 절차 안내 대상. 방문 수집 활성 변수 미설정 상태 유지.
- 검증 도구·결과·PNG는 `/tmp/ken-blog-layout-category`. 실제 Pages 최종 확인 진행 예정.
