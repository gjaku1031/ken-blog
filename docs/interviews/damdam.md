# 담담공방 쇼핑몰: 인터뷰 요약

문서를 쓰며 확인한 사실과 판단의 이유를 정리한 기록. 블로그에는 게시하지 않음. 마지막 정리 2026-10-11.

## 개발 형태와 담당 범위

- 외주 프로젝트. 지인의 소개로 받았음
- 2인 팀: 프론트엔드 1명, 백엔드와 인프라 1명(본인)
- 2025년 9월에 시작했음. 저장소를 중간에 옮겨 지금 저장소의 이력은 그보다 짧음
- 운영하던 사이트를 디자인을 크게 바꿔 다시 여는 중이고, 문서에는 운영 중으로 씀
- 상호와 도메인은 문서에 그대로 씀

## 누가 정했는가

- **무통장 입금만 받음**: 의뢰인의 요구
- **별도의 관리자 화면을 두지 않고 편집 모드로 운영함**: 의뢰인의 요구
- **Redis를 쓰지 않음**: 백엔드와 인프라를 한 사람이 맡고, 이용자가 월 50명에 못 미칠 것으로 예상해 정했음
- **자동 테스트**: 아직 없고 뒤에 작성할 예정임

## 직접 정한 것

- 재고 설계의 갈림길 16곳, 이미지 최적화, 응답 캐시의 선택은 모두 직접 고안했음. 재고는 비교안을 만들어 놓고 고르는 방식으로 정했음

## 문서 방향으로 정한 것

- 핵심 문제는 재고 정합성, 사진 전송량, 캐시된 응답의 노출 셋으로 잡음
- 기술 스택을 바꾼 이력은 쓰지 않고 현재 스택 기준으로 서술함
- 의뢰인이 이전에 어떻게 팔았는지 같은 개발 배경은 확인된 것이 없어 쓰지 않음. 의뢰 조건과 설계 제약만 적음

## 아직 하지 않은 것

- DB와 사진의 백업을 하지 않음
- CSRF 토큰은 아직 넣지 않았고, 넣을 예정임
- 저장소에 있는 브라우저 검사 스크립트는 쓰지 않음. 문서의 검증 근거로 적지 않음
