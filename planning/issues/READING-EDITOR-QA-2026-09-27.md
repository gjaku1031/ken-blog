# 읽기·블록 선택·출간 목록 QA 보정

## 요청과 범위

- Tech 본문을 한글 약 3글자만큼 확대. 현재 784px에서 836px로 52px 확대, 우측 레일 260px와 간격 36px 유지.
- 시리즈 목록 6개씩 이전·다음 페이지 이동. 현재 글이 포함된 페이지 최초 표시, 레일 내부 스크롤 제거.
- 선택 블록 표시선과 본문 사이 여백 확보, 빈 편집기 여백에서 드래그하여 여러 블록 선택.
- 출간 창의 Tech 시리즈 순서를 오른쪽 열로 이동.
- 새 글이 홈에만 표시되고 Tech 목록에 즉시 나타나지 않는 원인 확인·수정.
- 기존 사용자 작성 글과 QA 자료 보존. 글 주소·제목 크기·모바일 입력 동작 유지.

## 수용 기준

- 데스크톱 본문 836px, 좁은 화면 가로 넘침 없음.
- 시리즈 6개 이하 페이지 버튼 없음, 긴 목록의 처음·중간·마지막 페이지 이동과 현재 글 강조 유지.
- 페이지 버튼은 본문·주소를 변경하지 않으며 짧은 화면에서도 문서 스크롤로 접근 가능.
- 블록 선택 강조선 여백과 드래그 선택 피드백 확인. 본문 텍스트 선택·입력·기존 그룹 이동 유지.
- 출간 창 오른쪽 시리즈 순서와 모바일 한 열 순서 확인.
- 새 글 출간 후 Tech 재방문 시 최신 글·분류 수치 일치.

## 검증

- 신규 저장소 테스트 추가 없음. 웹 타입 검사·기존 검사 7개·정적 20경로 빌드·변경 공백 검사 통과.
- 실제 브라우저 읽기 14항목: 836px 본문·260px 레일, 현재 16번째 글의 13~16 목록, 6개 페이지 이동·키보드·양끝 버튼, URL/본문/스크롤 유지, 다른 글 이동 시 현재 페이지 재설정, 짧은 화면·390px 폭·6개 이하 목록 확인.
- 실제 브라우저 편집 18항목: 위·아래 박스 선택, 26px 선택 여백, 12px 본문 간격, 선택 후 키보드 그룹 이동, 기존 손잡이 그룹 드래그, 선택바 높이 보존, 텍스트 선택, 화면 끝 자동 스크롤, Escape/blur 정리, 모바일 가로 넘침 없음 확인.
- 출간 창: Tech 시리즈 순서의 오른쪽 배치, 주소 입력 없음, 390px 한 열 배치와 가로 넘침 없음 확인. 순서 값 변경 없음.
- Tech 원인: 서버 공개 피드는 사용자 작성 `테스트용`을 Home/Tech 양쪽 최상단으로 반환. 클라이언트 메모리 캐시가 재방문 조회를 생략하여 Tech만 출간 전 목록을 유지한 문제 확인.
- 피드 6항목: 브라우저 응답에서 새 글만 잠시 제외해 출간 전 캐시를 재현한 뒤, Home→Tech 재방문 시 신규 글 반영과 기존 2페이지 범위 재조회·중복 없음 확인. 분류·태그도 같은 갱신 흐름에 포함. 취소된 이전 요청의 잠금 해제 경쟁 방지.
- 검증은 운영 GET 전용 로컬 중계와 미저장 편집 원고·브라우저 응답 대체 사용. 사용자 글·QA 자료 저장/수정/삭제 없음. 서버 코드·DB·환경 변경 없음.
- 브라우저 런타임 오류 없음. 확인 도구의 비동기 로드/이동 애니메이션 대기·드래그 마지막 포인터 이벤트 보정 후 재확인. 선택 후 포커스 유지 문제는 첫 선택 손잡이로 포커스 연결하여 해결.
- 최종 커밋의 CI·GitHub Pages 및 실제 배포 화면 확인 대상.
