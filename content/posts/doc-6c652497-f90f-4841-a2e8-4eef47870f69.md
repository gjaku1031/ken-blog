## 스키마의 특징

### 연락처를 원문으로 두지 않음

학생의 모·부 연락처, 예약 연락처, 인증 요청, 문자 수신자는 모두 같은 세 열로 저장함.

| 열 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `*_ciphertext` | AES-256-GCM 암호문 | 관리자 명단 표시, 문자 발송 직전 복호화 |
| `*_digest` | 서버 키로 계산한 HMAC-SHA256 | 연락처로 학생·예약 찾기(일치 비교만) |
| `*_last4` | 끝 네 자리 | 현장 후보 검색, 가린 표시(`***-****-1234`) |

QR, 예약 증명, 예약 접근 토큰, 관리 세션, 멱등 키는 SHA-256 다이제스트로만 저장하고 원문과 대조함. QR만은 학부모가 예약 링크로 다시 볼 수 있도록 API 전용 키로 암호화한 사본을 함께 둠. 결정과 대안은 [주요 기술적 의사결정](/ken-blog/post/doc-faeef8eb-3ab9-4a39-840f-bfb6b01adbda/)의 P2에 있음.

### 부분 유니크 인덱스로 중복 예약 차단

| 인덱스 | 대상 행 | 막는 것 |
| --- | --- | --- |
| `family_bookings(session_id, contact_digest)` | 상태가 `RESERVED`·`CHECKED_IN` | 한 회차에서 한 연락처의 활성 예약 두 건 |
| `family_booking_students(session_id, student_id)` | `active`이고 재원생 | 한 학생이 한 회차의 두 예약에 동시에 속함 |
| `qr_credentials(family_booking_id)` | 상태가 `ACTIVE` | 한 예약에 쓸 수 있는 QR 두 개 |
| `booking_access_credentials(family_booking_id)` | 상태가 `ACTIVE` | 한 예약의 유효한 접근 토큰 두 개 |

취소된 예약은 인덱스 대상에서 빠지므로, 취소한 가족이 다시 예약하면 이전 행을 되살리지 않고 새 행을 만듦.[* [기준 마이그레이션](https://github.com/gjaku1031/npr-seminar/blob/e74a2a2/apps/api/prisma/migrations/20260717000000_corrected_nest_baseline/migration.sql)]

### 상태와 시각을 CHECK 제약으로 묶음

예약 상태와 시각 열이 서로 어긋나지 않도록 DB가 검사함. 예를 들어 `CANCELLED`는 `cancelled_at`이 있어야 하고, `RESERVED`는 입장·취소 시각이 모두 비어 있어야 함. QR·접근 토큰·인증 요청·스캐너 기기도 상태와 폐기 시각을 같은 방식으로 묶고, 상태·출처·결과 코드 열은 허용 값 목록을 CHECK로 둠. 애플리케이션 버그로 잘못된 조합을 쓰려 하면 커밋이 실패함.

### 추가 전용 감사 기록

예약 사건, 입장 사건, 인증 감사, 학생 이력, 스캐너 페어링 감사, 동기화 감사, 문자·시트 시도 기록은 갱신·삭제를 거부하는 트리거가 걸려 있음. 런타임 DB 역할에도 이 테이블들의 삭제 권한이 없음.[* [ERD 문서의 추가 전용 관계](https://github.com/gjaku1031/npr-seminar/blob/e74a2a2/apps/api/docs/erd.md)]

### FK 없이 공개 ID로 잇는 연결

| 연결 | 방식 |
| --- | --- |
| 문자 outbox → 예약·회차 | `family_booking_public_id`, `seminar_session_public_id`(UUID). FK 없이 공개 ID만 저장해, 예약 행이 지워져도 발송 기록은 남고 worker는 원장 테이블을 조인하지 않음 |
| 시트 매핑 → 회차 | `seminar_session_public_id`. 회차마다 매핑 하나(유니크) |
| 시트 outbox → 예약·참가자·학생 | 공개 ID와 예약 버전. 같은 사건·참가자에 대한 작업은 유니크 제약으로 하나 |
| 스캐너 세션 → 기기 | Redis 세션에 기기 공개 ID를 담고, 요청마다 DB의 활성 기기와 대조 |
