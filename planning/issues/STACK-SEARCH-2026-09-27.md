# 기술 스택 검색·프로젝트 직접 정렬·분야 선택 개선

## 요청·수용 기준

- 공식 자산을 사용하는 `VMware ESXi`, `Kotlin Multiplatform` 배지 추가. 표시명에 약어 괄호를 덧붙이지 않고 KMP 검색 지원.
- 기존 기술 이름과 명확한 별칭, 띄어쓰기·마침표·하이픈 차이를 허용하는 검색. 정확 일치 우선, 기존 선택·제거·정렬·출간 미리보기 유지.
- 글쓰기 드롭다운의 새 배지 등록·파일 선택 제거. 등록된 기술 선택 전용, 에이전트용 관리자 API 유지.
- 기존 운영 배지·로고·프로젝트 연결·원고 보존. 추가 자산/적용 기록은 저장소 밖 보관.
- Projects 카드의 기술 배지 글자·로고·여백 소폭 축소.
- 별도 순서 편집 화면 제거, 관리자 카드 직접 드래그 후 자동 저장·실패 복구·충돌 재조회.
- Notes 분야 선택을 테마 드롭다운으로 전환, 새 분야 입력·키보드·터치 지원 유지.
- 변경된 웹 범위의 타입·기존 검사·정적 빌드·브라우저 확인, 새로운 저장소 테스트 없음.

## 구현·검증

- 운영 `VMware ESXi` ID 86, `Kotlin Multiplatform` ID 87 등록 완료, 총 71개. 기존 69개 이름·ID·로고 해시 및 현재 프로젝트 연결 불변 확인. 공식 원본·PNG·적용 기록은 저장소 밖 0700/0600 보관.
- 정확한 표시 이름·별칭 우선 검색. 공백·점·하이픈·밑줄 차이 허용, `C++`·`C#` 구별 유지. 새 등록·이미지 업로드 UI 제거, 기존 선택·제거·드래그·출간 미리보기 유지.
- Projects 카드 배지 12px·로고 16px·간격 4px 적용. 1281px에서 Spring Boot·PostgreSQL·Classic ASP 한 줄 표시, 390px 라이트·다크 가로 넘침 없음 확인.
- 별도 순서 편집 컴포넌트 삭제. 관리자 카드 전체 마우스 드래그와 터치 손잡이·키보드 이동 후 자동 저장. 전체 페이지 로드 및 관리자 기준 순서 일치 후 활성화, 비표시 프로젝트 위치 보존. 저장 중 중복 요청 차단, 실패 롤백, 409 최신 목록 재조회.
- 분야 선택 combobox/listbox 전환. 테마·선택 표시·새 분야 입력·키보드·바깥 클릭·Escape·네이티브 터치·긴 이름 줄바꿈 확인.
- 웹 기존 검사 7개·타입 검사·17경로 정적 빌드·diff 검사 통과. 신규 저장소 테스트 없음.
- 격리 HTTP 프록시와 브라우저로 마우스 카드/제목 드래그·자동 저장 1회·새로고침 유지·Escape/CTA 취소·500 롤백·409 재조회·중복 저장 차단·390px 네이티브 터치·익명 정렬 비활성 확인. 일반 제목 클릭 이동 정상. 운영 순서 변경 없이 메모리 데이터로 저장 동작 검증.
- 실제 카탈로그로 별칭·표기 차이·정확 검색 우선·빈 결과·등록 메뉴/파일 입력 없음·ESXi/KMP 로고·선택/제거/순서/출간 미리보기 확인. 미저장 상태로 검증 종료, 런타임 오류 없음.
- 함께 존재하는 API·인프라·단축키 도움말·기존 작업 목록 변경은 이번 전달 대상에서 제외. 동일 SHA 원격 CI·Pages 및 배포 화면 최종 확인 대상.
