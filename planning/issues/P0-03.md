# P0-03: Next 화면과 상태 API 연결

상태: **계획 초안 — 승인 전** · 선행: P0-02 완료

## 문제

API 상태 조회와 오류 응답 계약은 존재하지만 Next 홈은 고정 준비 문구만 표시. 프론트가 API 응답과 장애를 화면에 구분해 표시할 연결 경로 필요.

## 포함 범위

- Next 서버에서 Spring의 `/api/v1/status`를 호출하는 최소 연결 구성.
- 서버 전용 환경변수로 API 주소 주입. 브라우저 번들에 내부 주소·비밀 설정 포함 없음.
- 정상 응답·예상한 HTTP 오류·연결 실패·시간 초과·잘못된 응답 본문 구분.
- 홈에 API 연결 상태와 실패 안내 표시. `UP`을 DB·외부 서비스 정상으로 확대 해석하지 않음.
- 요청 시간 제한·캐시 정책 명시, 런타임 호출과 빌드 시 호출 구분.
- 관련 TypeScript 함수·컴포넌트 JSDoc과 실행 안내, 로컬 학습 문서 작성.

## 제외 범위

로그인·게시글·DB·Redis·첨부파일, 완성된 블로그 디자인, 운영 배포·GitHub Pages 포함하지 않음. 이번 연결은 Next 서버 경유이며 브라우저의 Spring 직접 호출용 CORS 구성 없음.

## 완료 조건

- [ ] 정상 API를 연결한 홈에서 프로세스 응답 상태 표시.
- [ ] API 미기동·비정상 본문·HTTP 오류에서 화면 전체 오류 없이 안내 표시.
- [ ] 설정되지 않은 주소와 시간 초과의 처리 확인.
- [ ] 내부 API 주소가 브라우저 응답·번들에 포함되지 않음.
- [ ] API가 실행되지 않은 빌드 환경에서도 Next 빌드 가능.
- [ ] 타입 검사·빌드·브라우저·CI 검증 통과.

## 검증 방법

응답 변환과 실패 분기는 격리 테스트로 확인. 실제 Next·Spring 연결 후 브라우저에서 정상 화면 확인, 테스트용 API 중지 후 장애 화면 확인. 기존 운영 컨테이너 변경 없음. API 주소는 예시값만 문서화하고 실제 환경변수는 Git 제외.

승인 후 구체적인 코드·설정 추가. 이번 문서는 다음 작업 제안이며 구현 완료 기록이 아님.
