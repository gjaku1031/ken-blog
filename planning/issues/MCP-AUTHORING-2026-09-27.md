# VM 전용 MCP와 블로그 작성 기능

## 요청과 범위

- 기존 Spring Boot API 안의 MCP 통합, 별도 애플리케이션·컨테이너 추가 없음
- SSH로 접속한 VM의 클라이언트에서 로컬 MCP 사용, 공개 HTTPS·Tailscale 경로의 접근 차단
- 별도 OAuth·JWT·접근 토큰 발급 없이 VM 내부 신뢰 경계 적용, 기존 웹 MFA·JDBC 세션·CSRF 유지
- Tech·Projects 대문/문서·Notes 과목/회차 조회·작성·수정·출간 지원
- 기술 스택 목록·등록·이름 변경·로고 업로드/교체와 OCI 본문 이미지 첨부 지원
- 표·접기·위키 링크·주석·코드·인라인/블록 수식·Mermaid 등 실제 편집 문법을 작성 Skill과 참고 자료로 제공
- 맥에서 기존 SSH 연결을 사용해 설정할 수 있는 프롬프트 제공

## 구현 기준

- 표준 MCP SDK/Spring 통합의 Streamable HTTP 사용, 실제 의존성 호환성 확인
- 기본 비활성화, 로컬 주소·실제 접속 출처·Host·Origin·프록시 헤더 검사 및 공개 프록시 차단
- MCP 도구에서 기존 구체 서비스를 재사용하고 저장·출간의 revision과 원본 수정 시각 검증 유지
- 본문과 첨부/위키 연결 선언의 계약 일치, 실패 시 민감 정보 없는 구조화 오류 반환
- 첨부·로고는 명시 파일명·MIME·제한된 바이너리 입력, 임의 서버 파일·외부 URL 읽기 기능 제외
- 작성 Skill 원본과 MCP 참고 자료의 중복 관리 방지, 지원되지 않는 확장의 지원 완료 주장 없음
- 신규 저장소 테스트 코드 추가 없음, 임시 검증 도구와 격리 데이터에 의한 실제 호출 확인
