# 작업과 기록 기준

계획 작성 → 범위 승인 → 구현·검증 → 작은 커밋 → `main` 직접 push → 다음 계획 승인.

- PR 생성 없음. 후속 계획의 자동 승인 없음.
- 커밋은 영어 Conventional Commits. 문서·주석은 한국어, 문서는 명사형 종결.
- 계획별 문제·포함 및 제외 범위·완료 조건·실행한 검증을 기록.
- 실행하지 않은 테스트나 구현하지 않은 기능의 완료 표시 없음.
- author date는 2026년 5월부터 0~2일 간격으로 배치. 실제 작업 시점은 committer date와 검증 기록으로 구분.
- 완료 보고에는 커밋별 author date와 실제 push 날짜를 구분해 표기. GitHub의 push 시각은 소급 변경되지 않음.
- 비밀 설정은 저장소 밖에서 관리. `docs/study/`는 Git에서 제외하는 로컬 학습 자료.
- 공개 문서는 변경 이유·동작·검증 중심으로 작성.
