## 외부 조건과 구현 범위 구분

- 공개 HTTPS API 도메인·DNS/TLS와 Pages 실제 연결은 주소/운영 설정이 필요. 현재 값 없음. 코드의 연결 준비와 실제 공개 서비스 연결을 구분. 기존 운영 앱·DB·Redis 교체는 현재 금지 범위 유지.
- 메일은 실제 제공자/발신 주소/발송 권한 필요. 미설정 상태에서 보냈다는 성공 문구 또는 실제 초대 완료 표시 없음. 구현은 설정 가능한 발송 어댑터와 명확한 실패/미설정 경계를 포함.
- GA 공개 측정 ID는 `G-JDYNG61J70`. Data API의 속성 ID와 서비스계정 읽기 권한은 별도이며 측정 ID로 대체 불가. 실제 통계 미연결 시 샘플 수치 없음.
- 운영 MySQL·Redis의 로컬 비밀 설정 보관은 확인됐지만 현재 저장소의 GitHub Secrets/Variables는 비어 있음. 로컬 보관·CI 임시 환경·새 운영 배포 연결은 각각 별개 상태.

외부 조건이 없어도 독립 구현·격리 검증·문서화는 계속 진행. 필요한 계정/주소가 마련되지 않은 실제 외부 연결은 완료로 표시하지 않음.
