# 일반 본문 입력 흔들림 보정

## 요청과 조사

- 일반 본문 문단 입력 중 화면 떨림 지속 제보
- Safari 및 데스크톱 앱 내 브라우저에서 발생한다는 사용자 확인
- 활성 textarea의 입력 이벤트와 상태 반영마다 높이를 auto로 줄인 뒤 다시 늘리는 중복 측정 확인. 긴 문단의 한 글자 입력에서 실제 입력칸 style 변경 6회, 중간 auto 높이 3회 관측
- Chromium 프레임 측정에서는 제보된 가시적 진동을 재현하지 못함. 확인된 순간 높이 축소 경로의 제거와 입력 계약 보존으로 수정 범위 한정

## 수용 기준

- 긴 본문 중간·말미에서 연속 입력 시 불필요한 화면·커서 위치 진동 제거
- 줄바꿈·삭제·붙여넣기·한글 조합·화면 폭 변경의 자동 높이 및 입력 내용 보존
- 목록·접기·표 셀 자동 높이와 키보드 흐름 회귀 없음
- 운영 원고 변경 없이 격리 브라우저에서 수정 전후 비교, 기존 웹 검사·타입·정적 빌드 확인
- 동일 SHA CI·Pages와 실제 배포 코드 확인, 신규 저장소 테스트 추가 없음

## 구현·로컬 검증 — 2026-09-29

- 같은 부모의 CSS와 실제 폭을 쓰는 숨긴 고정 위치 복제 textarea로 필요한 높이 측정. 실제 입력칸 높이·문서 흐름·커서는 측정 중 유지, 최종 높이가 달라질 때만 반영
- 측정용 칸의 ID·name 제거 및 비노출·초점 제외·즉시 제거, 표 셀 측정에도 같은 경로 적용. 전역 스크롤 동작 변경 없음
- 동일 한 글자 입력의 실제 입력칸 style 변경 6회에서 0회, 중간 auto 높이 3회에서 0회 확인

- 아래 블록 비겹침·전체 내용 표시·측정 DOM 제거·브라우저 실행 오류 0건 확인. 격리 임시저장 요청에서 입력 원문 보존 확인
