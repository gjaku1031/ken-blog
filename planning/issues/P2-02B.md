## 문제와 시작 상태

## 구현 범위

- 정적 `/write/`의 새 Tech 원고, `?postId=양수`의 기존 글 수정, `?draftId=양수`의 편집본 이어쓰기. 두 ID 동시 지정·잘못된 ID는 안내. 관리자 전용이며 익명은 안전한 내부 returnTo 로그인, USER는 권한 안내. API 미설정·조회 실패·삭제된 원고 상태 구분.
- 기존 글에 편집본이 있으면 이어쓰기 경로를 안내하고 기존 편집본을 덮지 않음. 새 저장 후 URL에 draftId 반영해 새로고침 복원. 기존 원문을 바로 PUT하지 않고 P2-02A API만 사용해 작업 내용 저장.
- 헤더 유지·글쓰기 푸터 숨김, 760px 편집 열, 제목·분류·태그, 수동 저장·출간 버튼. 공개 읽기의 관리자 수정 링크와 Tech 새 글 진입 연결.
- 문단·h1~h3·글머리/번호 목록·할 일·인용·코드·구분선 블록. 편집할 블록만 textarea, 나머지는 안전한 렌더링. 안정적 블록 ID, Enter 분할/빈 목록 탈출·Backspace 변환/안전한 합치기·화살표 이동·Esc·코드 Ctrl/⌘ Enter·키보드 접근을 제공. 한글 조합 중 키 가로채기 금지, 조합 완료 후 단축키 확인. 제목·목록·할 일·인용의 Shift+Enter는 차단하고 도움말에 명시해 재로드 시 문단으로 분리되는 손실 방지. 문단·코드는 줄바꿈 허용.
- 지원하지 않는 표·중첩 details·이미지·수식·Mermaid·참조 정의 등은 원문 블록으로 보존. 다른 블록만 바꾸어 저장해도 원래 원문을 조용히 버리거나 평탄화하지 않음. 로드→저장 무수정 보존과 수정 후 재로드 고정점 검증. 원문 보존을 해당 기능의 전용 편집/렌더링 완료로 표시하지 않음.
- 손잡이 이동과 키보드 위/아래 이동으로 블록 순서 변경. 모바일에서 손잡이에 의존하지 않음. 원문 블록의 경계 앞 Backspace가 내용을 삭제하지 않도록 안전한 선택/이동 처리.
- 출간 시트에서 slug·PUBLIC/PRIVATE 확인, 제목·길이·본문/태그 제한의 안내. 수동 저장 성공 결과의 revision으로만 출간. 출간 성공 후 정적 글 주소로 이동. 저장 중 중복 클릭과 저장 이후 추가 편집을 구분하고 성공 표시가 미저장 내용을 덮지 않음.
- 409 충돌이나 400/404/503·네트워크 오류에서 입력 원고 유지, 명시적 재조회 전 자동 덮어쓰기 없음. 세션 변경/로그아웃 시 관리자 원문 즉시 폐기하고 늦은 응답 무시. 비밀번호·토큰·원고를 localStorage에 저장하지 않음.
- `/admin/drafts/`에 실제 편집본 10개 번호 페이징·이어쓰기·revision 조건 삭제·빈 상태. 삭제 확인, 마지막 페이지 삭제 뒤 유효 페이지 복구. 미구현 관리자 기능으로 가는 가짜 메뉴 없음.
- API 클라이언트의 PUT/DELETE와 ADMIN 읽기/CSRF 쓰기 경계 확장. 백엔드는 기존 게시글 상세·분류·태그 GET을 정확한 인증 origin에만 허용하도록 CORS 추가. 기존 세션/권한/ProblemDetail·게시글 저장 계약 변경 없음.
- 한국어 JSDoc/KDoc과 기능별 파일 분리, 기존 CI 정적 경로 확인과 실행 문서 갱신. 학습 문서 추가 없음.
