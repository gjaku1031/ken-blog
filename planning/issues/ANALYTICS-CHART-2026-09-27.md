# 방문자 그래프 가독성과 로그인 안내 정리

## 문제·범위

- 선택 기간과 무관하게 GA가 반환한 날짜 행만 늘여 그려 7·30·90일의 막대 폭이 같고 날짜·수치 파악이 어려운 상태.
- READY 보고서의 KST 날짜 범위 전체 보존, 방문 기록이 없는 날 0명 표시. 미연결·오류·빈 결과 상태를 가짜 실측값으로 전환하지 않음.
- 기간별 막대 밀도·날짜 눈금·방문자 수 눈금·hover/focus/touch 상세 정보 제공. 좁은 화면의 날짜 겹침·툴팁 잘림·가로 넘침 방지.
- 로그인 인증 앱 입력칸 아래 지정된 도움 문구 제거. 인증·복구 기능 유지.
- 기존 GA4 연결·관리자 MFA·사용자 콘텐츠 보존, 새 테스트 파일·새 차트 의존성 추가 없음.

## 검증

- 기존 API `clean verify` 28개·웹 타입검사/기존 7개·최종 정적 빌드·diff 검사 통과. 신규 테스트 파일·차트 라이브러리 추가 없음.
- 실제 GA4 보고서와 비교하여 7·30·90일의 연속 날짜 수와 기존 방문자 값 보존 확인. 2026-09-27 기준 7일 09.21~09.27, 30일 08.29~09.27, 90일 06.30~09.27. 누락 날짜만 0명 처리, 다른 지표·표 응답 동일.
- 정적 브라우저 1365/1115/390px에서 기간별 막대 폭·실측 높이·첫/끝 날짜·정수 방문자 축·툴팁 경계·날짜 겹침·가로 넘침 확인. 라이트/다크 화면 확인.
- 한 번의 Tab 진입·좌우/Home/End 날짜 이동·Escape 닫기·0명 슬롯 호버·실제 모바일 터치 확인. 터치 드래그 종료 시 처음 날짜로 되돌아가던 문제 보정 후 마지막 날짜 유지 재검증.
- 브라우저 응답 대체로 EMPTY/UNCONFIGURED/ERROR의 구분과 가짜 수치 미표시, 전부 0인 막대·큰 방문자 수 툴팁 확인. 실제 GA 응답 복원 후 재조회 확인. 런타임 오류 없음.
- 로그인 기본 모드 지정 문구와 불필요한 aria-describedby 제거 확인. 복구 모드 도움말·입력 접근성 연결 유지.
- 운영 API 배포 후 7·30·90일 응답이 격리 검증 응답과 동일함 확인. 공인 health UP·기존 MFA 세션 유지·익명 분석 요청 401·환경 파일 변경 없음 확인. DB·사용자 글·QA 데이터 변경 없음. Pages 반영과 최종 원격 검사 확인 대상.
