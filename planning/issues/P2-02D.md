## 구현 범위와 결정

- 접기 하나를 상위 `toggle` 블록, 내부를 별도 MarkdownDocument로 구성. 상위 이동·끌기·삭제는 제목과 모든 내부 블록을 함께 처리. 기존 Markdown 저장 API와 revision/세션/CSRF 계약 유지.
- 한 단계의 명확한 무속성 `<details>`와 한 줄 `<summary>`만 편집 가능으로 분류. 같은 줄/다음 줄 summary 허용. 원본 wrapper·내부 source·CRLF·구분 공백을 별도 보존하며 무수정은 전체 원문 반환. 중첩 접기·불균형·속성 HTML·모호한 summary는 전체 원문 블록 유지. 복잡한 구조를 단순 모델로 자동 평탄화하지 않음.
- 접기 제목 입력과 내부 기본 블록·표 편집. 제목의 태그 문자를 이스케이프하여 summary 경계 주입 방지. 원문 보존 블록은 내부에서도 읽기 전용. 안쪽 편집기의 접기 생성은 금지하여 한 단계 편집 계약 명확화.
- 문단에서 `> ` 또는 `/접기`·`/toggle` Enter 및 접기 추가 버튼으로 생성. `| ` 인용과 파이프 표 단축키 유지. 한글 조합 이벤트 중 구조 변경 없음. 명령은 전체 문단과 커서 끝 조건에서만 처리.
- 제목 Enter로 안쪽 첫 블록 포커스, 내부 빈 문단 Enter로 접기 밖에 이어 쓰기. 텍스트 블록의 Tab으로 바로 앞 접기에 현재 블록 편입. 내부 텍스트 블록의 Shift+Tab은 현재 블록부터 뒤의 형제 블록을 함께 밖으로 꺼내 문서 순서를 유지. 중간 빈 문단에서 밖으로 나갈 때도 뒤의 내용이 뒤집히지 않도록 같은 경계 사용. 표 셀의 기본 Tab/Shift+Tab 포커스는 유지하고, 표·원문 등도 이동 버튼으로 편입/꺼내기 제공. 안내 문구에 실제 단축키 동작 명시.
- 접기 해제는 자식 내용을 상위 문서에 남기고 wrapper만 제거. 삭제는 확인 후 전체 그룹 삭제. 빈 제목 Enter는 내용이 없을 때만 빈 문단으로 복귀하며 내용이 있으면 내부로 이동. Backspace로 제목이나 자식이 조용히 사라지지 않도록 경계 처리.
- 키보드 포커스·Esc·드래그/이동 버튼·출간 중 disabled 전파, 내부 조작의 이벤트가 바깥 그룹 이동으로 잘못 전파되지 않는지 확인. 라이트·다크·작은 화면의 들여쓰기·내부 스크롤 유지.
- README·편집 문서·계획·체크리스트를 구현/미구현 경계에 맞게 갱신.
