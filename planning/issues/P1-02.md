# P1-02: Spring Security·로그인 기반

상태: **초기 구현 완료 — 현재 JDBC 구성과 최종 검증은 P1-02A에서 관리.**

## 현재 기준

기준 커밋 `46a1010`. 관리자 계정·Spring Security 로그인·로그아웃·현재 사용자·CSRF·권한·세션 ID 교체·ProblemDetail 구현과 `post`, `account`, `auth`, `status`, `global` 패키지 정리 반영. 세션 저장소는 이 커밋에서 Redis.

계정 저장소는 Spring Data JPA `AccountRepository : JpaRepository<UserEntity, Long>` 인터페이스의 `findByUsername` 파생 쿼리와 상속 `count`·`saveAndFlush` 사용. `AccountService`와 인증 조회 서비스는 구체 클래스로 유지.

Redis 세션 구성의 로컬 검사·격리 실행 검증 완료, 패키지 정리 후 clean package와 [CI](https://github.com/gjaku1031/ken-blog/actions/runs/36145485517)·[Pages](https://github.com/gjaku1031/ken-blog/actions/runs/36145485534) 성공. 기존 VM 배포 앱을 이 소스로 교체한 상태는 아님.

사용자의 최신 요청으로 최종 인증 방식은 Spring Session JDBC. 중간 JWT 검토·미완성 작업은 정리했으며 사용자 승인 후 JDBC 전환 구현·격리 검증·원격 반영 완료. 현재 구성·최종 검증 결과는 [P1-02A](P1-02A.md)로 일원화.
