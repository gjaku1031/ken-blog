# 직접 HTTPS 전환과 남은 편집 기능 보완

## 요청과 범위

- 사용자 요청: 미완성 부분 보완, Nginx를 사용하지 않는 코드·운영 구성으로 전환, 불필요한 임시자료 정리.
- 기준 main a95f486. 이미 남아 있던 direct-https·Compose·인증서 스크립트 미커밋 변경을 보존하고 이어서 검토.
- Spring 내장 Tomcat의 HTTPS와 HTTP-01 경로, 내부 HTTP/MCP 커넥터 분리. 비루트 실행과 인증서 자동 재로딩 유지.
- 위키 미리보기 대상 조회·오래된 응답 폐기·원문 보존, 콘텐츠 변경 경계의 명시적 선언 및 폐기 기능 주석 정리.
- 공개 Pages·관리자 주소·원고·첨부·DB/Flyway·MFA/JDBC 세션 보존. Thymeleaf 전면 이행이나 화면 재설계는 이번 범위에 포함하지 않음.
- Nginx 참조는 대체 경로 검증 후 제거. DB 백업·복원·인증서 발급 원본·복구자료·PORT 자료는 삭제 대상이 아님.

## 검증 계획

- 루트 타입 검사·기존 Maven 검사·빌드.
- 격리 환경에서 TLS 기본 응답·HTTP-01·인증서 재로딩·공개 MCP 차단·내부 MCP 허용·관리자 인증/CSRF 확인.
- 위키 링크가 본문·주석에서 올바른 Pages 주소를 사용하고 없는 글/실패/늦은 응답이 원문이나 미리보기를 훼손하지 않는지 확인.
- 콘텐츠 변경의 선언 누락 점검과 기존 배포 잠금 의미 보존.
- 전환 전후 데이터 해시·실행 포트·인증서·관리자 자산·배포 상태 대조. 실패 시 이전 구성 복구.
- 최종 관련 diff 확인, 소유 임시환경/빌드 산출물 정리. 실행하지 않은 항목은 통과로 표시하지 않음.

## 보존과 정리 범위

- Nginx 설정/Dockerfile과 갱신 스크립트의 gateway 분기는 직접HTTPS 확인 후 제거. 자동 갱신은 Certbot→원자적PEM 설치→Spring SSL bundle 재로딩 경로 사용.
- DB 백업·복원·ACME·키 설치 도구, 운영 인증서 원본, rollback 이미지·백업 유지. 과거 검증 기록과 아키텍처 도면의 Nginx 표기는 당시 구성 이력으로 보존.
- 별도 PORT/CLEANUP 및 전달받은 migration 설계 보존. 이번 격리 컨테이너·테스트 DB/사용자·시험 키·임시 쿠키·빌드 산출물만 종료/정리 대상으로 한정.
