# 블로그 테마 404 화면

## 요청·수용 기준

- 잘못된 `/projectss/` 주소에서 Next 기본 영어 화면을 블로그 테마와 한국어 안내로 교체.
- 공통 헤더·푸터·밝은/어두운 테마 유지. 404·짧은 안내·홈 및 프로젝트 목록 링크 제공.
- GitHub Pages 정적 `404.html` 유지, 알 수 없는 주소의 HTTP 404·basePath 링크·모바일 폭·키보드 동작 검증.
- API·사용자 데이터·글 저장과 무관한 화면 변경, 새 저장소 테스트 추가 없음.

## 진행

- 전역 not-found 컴포넌트와 전용 CSS 구현 중. 이전 순서 기능 c3884c7 운영 API 반영 완료, 동일 SHA Pages·CI 및 실제 화면 검증 병행.

- `app/not-found.tsx`·전용 CSS 구현, 기존 셸 안에 단일 main 영역과 404/안내/두 복귀 링크 배치.
