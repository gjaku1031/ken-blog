## 코드 블록

```typescript
type Point = { x: number; y: number };
const length = ({ x, y }: Point): number => Math.hypot(x, y);
console.log(length({ x: 3, y: 4 })); // 5
```

## 코드와 연결된 수식

위 함수가 계산하는 거리는 $\sqrt{x^2+y^2}$다. 코드에서는 제곱과 제곱근 계산을 직접 풀어 쓰는 대신 길이를 구하는 함수를 사용했다.

## 표로 값 비교하기

| x | y | 길이 | 설명 |
| ---: | ---: | ---: | --- |
| 3 | 4 | 5 | 직각삼각형의 빗변 |
| 0 | 1 | 1 | 단위벡터 |
| 0 | 0 | 0 | 영벡터 |
