# P0-03: Next 화면과 상태 API 연결

상태: **완료 — main 반영·CI 통과** · 선행: P0-02 완료

> 이 단계의 Next 서버 호출은 당시 검증 기록. 현재 배포 구조는 [P0-04](P0-04.md)의 정적 Pages·브라우저 호출로 대체.

## 문제

API 상태 조회와 오류 응답 계약은 존재하지만 Next 홈은 고정 준비 문구만 표시. 프론트가 API 응답과 장애를 화면에 구분해 표시할 연결 경로 필요.

## 포함 범위

- Next 서버에서 Spring의 `/api/v1/status`를 호출하는 최소 연결 구성.
- 서버 전용 환경변수로 API 주소 주입. 브라우저 번들에 내부 주소·비밀 설정 포함 없음.
- 정상 응답·예상한 HTTP 오류·연결 실패·시간 초과·잘못된 응답 본문 구분.
- 홈에 API 연결 상태와 실패 안내 표시. `UP`을 DB·외부 서비스 정상으로 확대 해석하지 않음.
- 요청 시간 제한·캐시 정책 명시, 런타임 호출과 빌드 시 호출 구분.
- 관련 TypeScript 함수·컴포넌트 JSDoc과 실행 안내, 로컬 학습 문서 작성.

## 제외 범위

로그인·게시글·DB·Redis·첨부파일, 완성된 블로그 디자인, 운영 배포·GitHub Pages 포함하지 않음. 이번 연결은 Next 서버 경유이며 브라우저의 Spring 직접 호출용 CORS 구성 없음.

## 완료 조건

- [x] 정상 API를 연결한 홈에서 프로세스 응답 상태 표시.
- [x] API 미기동·비정상 본문·HTTP 오류에서 화면 전체 오류 없이 안내 표시.
- [x] 설정되지 않은 주소와 시간 초과의 처리 확인.
- [x] 내부 API 주소가 브라우저 응답·번들에 포함되지 않음.
- [x] API가 실행되지 않은 빌드 환경에서도 Next 빌드 가능.
- [x] 타입 검사·빌드·브라우저·CI 검증 통과.

## 검증 방법

응답 변환과 실패 분기는 격리 테스트로 확인. 실제 Next·Spring 연결 후 브라우저에서 정상 화면 확인, 테스트용 API 중지 후 장애 화면 확인. 기존 운영 컨테이너 변경 없음. API 주소는 예시값만 문서화하고 실제 환경변수는 Git 제외.

## 구현 기준

- 서버 전용 `API_BASE_URL`로 Spring 주소 설정. 개발용 예시는 `http://127.0.0.1:8081`.
- 홈 요청 시 서버에서 상태 조회. 상태 응답 캐시 사용 없음, 호출 제한 시간은 3초.
- 내부 URL·응답 원문·예외 메시지는 화면에 노출하지 않음. 정상·미설정·잘못된 설정·HTTP 오류·연결 실패·시간 초과·응답 형식 오류를 공개 문구로 표시.
- 클라이언트 상태 관리나 별도 중계 API 없이 Server Component에서 호출.
- CI에 응답 처리 테스트 추가. 로컬에서는 실제 Next·Spring을 사용해 정상과 장애 화면 확인.

현재 진행 요청으로 P0-03 범위 승인. 다음 작업은 별도 승인 필요.

## 검증 결과

실제 검증일: 2026-09-25. 코드 기준 커밋: `4e52a6c`.

- `npm ci`, `npm test`, `npm run typecheck`, API 주소 미설정 상태의 `npm run build` 통과.
- Node 테스트 6개 통과. 정상 응답·설정 오류·HTTP 오류·연결 실패·JSON 계약 위반·본문 수신 시간 초과 확인.
- 홈은 요청 시 동적 렌더링. 실제 Spring JAR와 Next 프로덕션 서버 연결 후 정상 문구 확인.
- 테스트용 Spring만 종료한 뒤 같은 Next에서 연결 실패 안내 확인. 두 상태의 브라우저 콘솔·페이지 오류 없음.
- 브라우저 요청은 Next 리소스만 포함. Spring 직접 요청 없음.
- API 중지 상태의 HTML·RSC 응답과 클라이언트 JS 6개에서 테스트용 내부 주소·환경변수 이름·내부 표식 미포함 확인.
- 정상 화면의 문구·렌더링은 확인했으나 정상 상태 HTML·RSC의 별도 문자열 검사는 수행하지 않음. 개발 모드 출력의 비노출 검증은 포함하지 않음.
- 브라우저 및 테스트용 Spring·Next 프로세스 종료. 기존 운영 컨테이너 변경 없음.
- [GitHub CI](https://github.com/gjaku1031/ken-blog/actions/runs/36129596739)의 API·Web 작업 통과. Web 상태 테스트와 미설정 상태의 프로덕션 홈 응답 포함.
