# 주석 왕복 탐색·말풍선 링크·기술 배지 축소

## 문제와 범위

- 주석 목록 이름이 텍스트여서 이름 클릭으로 본문 복귀 불가, 기존 복귀 링크는 첫 참조만 지정하는 상태
- 말풍선에서 주석 링크를 일반 텍스트로 표시하여 직접 이동 불가
- Projects 목록과 프로젝트 대문의 기술 배지 추가 축소 요청
- 공개 읽기 UI만 보정, 원고·프로젝트 순서·기술 카탈로그·인증·API·DB 변경 제외

## 수용 기준

- 주석 목록 이름과 복귀 링크에서 해당 주석을 누른 본문 위치로 이동, 방문 기록이 없으면 첫 참조로 이동
- 동일 주석 다중 참조·접힌 내용·포커스·도착 강조·동작 줄이기 유지, 문서 교체 시 이전 참조 기록 초기화
- 읽기 말풍선 내 안전한 링크 직접 실행, 포인터 이동과 키보드 탐색 중 유지 및 Escape 닫기
- 편집 미리보기 링크 비활성 및 기존 URL 검증 유지
- 목록·대문 기술 배지의 글자·아이콘·안쪽 여백 축소, 편집 제어 크기 보존
- 기존 웹 검사·타입·정적 빌드 및 로컬 브라우저 검증, 최종 main의 CI·Pages와 실제 서비스 확인

## 진행

- 구현 및 로컬 검증 완료, 신규 저장소 테스트 추가 없음
- 목록 배지 높이 24→22px·글자 12→11.5px·로고 16→14px, 대문 배지 높이 28→24px·글자 12.5→11.5px·로고 20→16px 적용
- 읽기 팝오버의 링크·키보드 순서·Escape 복귀, 문서별 최근 클릭 참조와 첫 참조 fallback 적용
- 동일 SHA 원격 CI·Pages와 실제 서비스 확인 대상

## 검증 기록

- 웹 기존 7개 검사·타입 검사·정적 빌드·공개 스냅샷 동일성·diff 검사 통과
- 공개 읽기 응답과 브라우저 전용 임시 본문을 사용한 검증, 운영 콘텐츠 쓰기 없음
- 중복 주석의 실제 클릭 위치 복귀·포커스·강조, 처음 방문한 주석의 첫 참조 복귀, 접힌 원래 위치 자동 펼치기 확인
- Tab으로 팝오버 진입·링크 사이 이동·본문 순서 이어가기, Shift+Tab 원래 참조 복귀·Escape 닫기 확인
- 데스크톱 hover 조건을 설정한 headless 브라우저의 마우스 이동으로 참조와 팝오버 사이 유지·링크 이동 확인
- 긴 모바일 팝오버 내부 스크롤과 링크 초점 유지, 실제 공개 주석의 외부 링크 새 탭·noopener/noreferrer 확인
- 390px 터치 입력으로 주석 목록 이동·이름 클릭 복귀, 동작 줄이기 설정에서 즉시 스크롤 확인
- 1082/390px 목록·대문 각각 라이트/다크 화면과 배지 실제 크기·가로 넘침 없음 확인, 실행 오류 0건
- 편집 미리보기의 링크 비활성 분기 및 기존 URI 검증 유지 코드 검토, 인증 편집 저장 흐름의 추가 변경 없음
- 임시 검증 자료 `/tmp/ken-blog-annotation-navigation`, 운영 API·원고·기술 카탈로그 변경 없음
