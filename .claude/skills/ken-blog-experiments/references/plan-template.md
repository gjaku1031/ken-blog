# 실험 계획서 틀

확증 실험은 실행 전에 이 틀을 채워 실험 디렉터리(예: `experiments/<날짜>/<이름>/PLAN.md`)에 두고, 입력·정답·스크립트와 함께 커밋하거나 해시를 `freeze_manifest.json`에 적어 고정한다. 실행 뒤에는 이 파일을 고치지 않고, 바뀐 것은 맨 아래 '계획 변경 기록'에만 추가한다.
