# 프론트엔드 상태·렌더링 결정

기준일: 2026-10-03. 공개 화면은 정적 HTML, 관리자 화면은 인증된 메타데이터 관리 유지. 전체 배치·배포 경계는 [인프라 ADR](ADR_infra.md), 원고·공개 범위는 [애플리케이션 ADR](ADR_application.md) 참조.

## 관리자 비동기 작업의 소유권

저장 중 창을 닫고 다른 글을 열거나, 이전·다음 페이지를 빠르게 누르면 늦은 응답이 현재 입력·목록을 덮는 문제가 배경. 저장 작업은 시작한 세션과 대화상자 본문을 기억하고, 동일한 세션·본문에만 창 닫기와 오류 표시 적용. 목록 조회는 이전 요청을 취소하고 현재 요청의 응답만 반영. 페이지 이동은 글만 조회하고 기존 분류·태그·시리즈·기술 선택 목록 재사용. 저장 뒤에는 연결 수와 선택 목록 갱신.

저장 성공과 후속 조회 실패를 별도 결과로 처리. 생성은 성공했지만 목록 조회가 실패한 경우 화면에 저장 완료와 새로고침 실패를 함께 표시. 생성 요청 자동 재시도 없음. 모든 작업 중 화면 전체를 잠그는 대안은 다른 글 열기와 탐색을 제한하므로 제외. 서버의 트랜잭션·CSRF·세션 인증 계약 유지.

## 공개 탐색 데이터와 접근성

태그는 구분 문자열 대신 JSON 배열로 전달하여 이름의 `|` 보존. 이전 slug 쿼리 주소는 빌드에서 확정한 공개 대상 표로만 이동. 존재하지 않는 주소는 해당 목록으로 복귀하며 공개 해제된 글을 추측하거나 관리자 API로 조회하지 않음.

공개 snapshot v2에 선택적 `categories` 목록 추가. 공개 글에 지정된 분류와 부모의 ID·경로·표시 이름·순서만 포함하고 빈 분류·비공개 글 전용 분류·관리자 건수 제외. 같은 일관 읽기에서 수집하고 revision 계산에 포함하여 부모 순서 변경도 재생성 검사 대상. 구 API 응답에서는 경로 기반 부모 표시를 유지하므로 API를 먼저 반영한 뒤 Pages를 발행해야 모든 표시 이름·순서가 적용됨. 인증된 전체 분류 트리를 Pages 빌드에 전달하는 대안은 공개 범위를 넓히므로 제외.

넓은 본문 표는 모든 화면 폭에서 내부 스크롤 제공. 검색 입력의 키보드 포커스는 실제 `:focus-visible`로 표시. 보조 글자 색은 두 테마의 기본·카드·입력 배경에서 일반 텍스트 대비 4.5:1 이상으로 검증. 태그 선택 개수 오류는 선택 제거 후 해제.

## 정적 본문과 자산의 처리 비용

첨부 다운로드 주소를 확정하기 위해 본문 전체를 두 번 렌더하던 방식을 대체. 준비 단계에서 AST·첨부·위키·목차 정보를 만들고, 같은 AST에 공개 주소를 적용하여 최종 HTML을 한 번 생성. 수식·주석·위키의 제외 영역 검사도 같은 수식 AST 재사용. 문서 경계에서 CRLF·CR을 LF로 통일하여 행 번호·제목 ID 일치. 파서별 보안 한도와 HTML 정화 경계 유지. 전역 원고 캐시는 공개 해제·입력 변경 시 무효화 부담이 있으므로 미도입.

공통 화면과 상세 본문 자산 분리. KaTeX·본문 CSS·본문 상호작용은 상세 화면에서만 로드. 글쓰기 폼 코드·CSS는 관리자 확인 후 실제 작성 클릭에서 로드하며, CSS 로딩 완료 뒤 창 표시. 별도 CSS를 자동 로딩한다고 가정하지 않고 빌드 manifest와 템플릿·로더에서 주소 연결. manifest의 모든 진입 자산도 캐시 검증 대상.

검색 본문은 HTML의 카드 속성에서 내용 해시가 있는 별도 공개 JSON 색인으로 이동. 검색 화면에서 한 번 조회하고 최신 조건의 결과를 20개씩 DOM에 표시. 카드 HTML은 자동 이스케이프하는 기존 템플릿 출력이며 검색어를 HTML로 삽입하지 않음. 일반 목록은 정적 전체 링크를 유지하고 20개씩 표시. JavaScript 비활성 시 검색 대신 전체 공개 글 링크 제공. 키 입력마다 중복 검색하지 않고 기존 180ms 입력 지연과 한글 조합 대기 적용. 외부 검색 서비스나 SPA 라우터 도입 없음.

Mermaid는 화면 240px 이내로 접근한 도식만 렌더. 테마 변경·문서 분리 시 이전 예약 취소, 반복 interval 제거. 기존 원문·SVG 검증 뒤의 결과만 테마·원문 기준 최대 16개 보관. 목차는 크기·이미지·접기·글꼴 변경 시 제목 위치를 갱신하고 스크롤 중에는 저장한 좌표 이분 탐색. PNG·JPEG 헤더에서 읽은 크기와 JPEG EXIF 방향을 정적 이미지 속성에 반영하고 테마별 대체 이미지의 크기도 보존. 이미지 전체 디코딩·변환을 수행한다는 보장은 없음.

## 검증과 적용 상태

타입 검사·빈 사이트 생성과 Node 검사 26개 통과. Chromium 회귀 검사 12개로 늦은 저장 응답, 페이지 응답 역전·선택 목록 재사용, 저장 후 조회 실패, 태그 개수 오류, 공개 태그·분류, 이전 주소, 표 스크롤, 검색 포커스, 검색 색인·추가 표시, 폼 지연 로드, Mermaid 지연·테마 전환, 접기·문서 끝 목차 확인. 혼합 Markdown의 재렌더 일치·HTML/이미지 경계·줄바꿈·이미지 크기 검증 포함. MySQL 기반 분류 통합 검사 5개로 공개 분류·부모만 포함, 표시 이름·순서 보존, 부모 순서 변경 시 revision 변경 확인.

`npm test`는 타입 검사·빈 사이트 생성·Node 회귀 검사, `npm run test:browser`는 가상 공개 데이터·모의 관리자 API의 Chromium 검사. PR·작업 브랜치의 Frontend workflow는 저장소 읽기 권한만 사용하며 API·Pages 배포 자격 증명 없이 실행. Pages 배포의 실제 snapshot·revision 확인은 기존 workflow에서 별도 수행. 기존 인프라 ADR의 빈 사이트 중심 검사 설명을 이 기준으로 대체.

로컬 구현·검증 결과이며 운영 API·Pages 배포 완료를 뜻하지 않음.
