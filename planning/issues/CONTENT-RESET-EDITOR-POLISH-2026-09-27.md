# 콘텐츠 정리와 홈·편집기 후속 보정

## 요청과 범위

- 사용자 QA 종료에 따른 운영 콘텐츠 초기화 요청. 최신 확정 보존 대상은 관리자 로그인·MFA·복구 코드·기존 세션, 기술 스택 66개와 로고, 새로 저장한 홈 소개와 사진 참조.
- 글·태그·프로젝트·과목·분류·임시저장·첨부와 콘텐츠 연결 행 삭제. DB 스키마·Flyway·실행 설정·Google Analytics 연결 및 외부 통계 유지.
- 홈 소개 GitHub·이메일 링크의 카드 하단 정렬, 편집기 위아래 이동 버튼 제거, 마지막 내용 다음 빈 입력 문단 유지, 단축키 도움말 가로 넘침 제거.
- 후속 요청: 프로젝트 기본 양식의 빈 목록 항목이 편집 불가 원문으로 잠기는 문제 수정, 코드 언어 선택을 테마 드롭다운으로 전환.

## 수용 기준

- 저장소 밖 비공개 DB·첨부 백업 및 삭제 SQL 격리 리허설. 동일 트랜잭션 안에서 삭제 대상 0건·보존 테이블 행 해시 일치 확인 후 커밋.
- 첨부의 정확한 객체 키만 삭제, 기술 로고 66개 내용 해시 보존. 해당 글의 공개 본문 캐시만 정리.
- 기존 로그인 세션·운영 건강 상태·홈 소개·빈 목록 확인. 새 테스트 글·복구 코드 소비 없음.
- 소개가 길어져도 링크 겹침 없음. 빈 문단 입력·삭제·이동·실행 취소와 입력기 조합 안정성, 불필요한 말미 빈 줄 누적 및 저장 변경 방지.
- 도움말 전체 설명 확인, 데스크톱·모바일 가로 넘침 없음. 드래그·키보드 블록 이동 유지.

## 진행

- 실제 운영 사전 확인: 글 110개, 임시저장 12개, 프로젝트 6개, 과목 10개, 분류 19개, 첨부 5개, 기술 스택 66개. 태그는 글 연결 테이블에 저장되는 구조 확인.
- 신선한 DB 덤프·첨부 5개 백업 및 로고 66개 원문 해시 확인 완료. 별도 로컬 복원 스키마에서 삭제·보존 검사와 롤백 원복 리허설 통과 후 해당 임시 스키마 제거.
- 운영 API의 짧은 정지 중 최종 백업, 삭제 대상 12개 테이블 0건 및 보존 대상 9개 테이블 전체 행 해시 동일 확인 후 트랜잭션 커밋 완료. 첨부 5개 객체 삭제·기술 로고 66개 해시 보존 및 운영 API 정상 재가동 확인.
- 기존 MFA 세션·관리/공개 빈 목록·홈 소개·기술 66개 응답 검증 완료. 실제 Pages 홈·Tech·Projects·Notes·글 관리의 빈 상태와 홈 소개 보존 확인, 런타임 오류 없음. 복구 코드 소비 없음.
- 홈 소개 링크 하단 정렬, 이동 화살표 제거 및 드래그·Alt+방향키 이동 유지. 화면 전용 말미 문단은 저장 대상에서 제외, Enter로 만든 빈 문단만 원고에 반영.
- 단독 `-`·번호·체크 목록의 빈 항목을 편집 가능한 목록으로 해석. 복잡한 원문 형식의 보존 동작 유지.
- 코드 언어에 검색·키보드·직접 입력 가능한 테마 드롭다운 적용. 화면·고정 도구막대의 남은 공간에 따라 위아래 열림 및 높이 조절.
- 제목과 프로젝트 이름의 관계, 반복되는 마크다운 단축키·블록 조작 설명 제거. 짧은 본문 입력 표시·필드 이름·오류·저장 상태 유지, 상세 조작법은 선택해서 여는 도움말에 통합.

## 검증

- 웹 타입 검사·기존 테스트 7개·최종 정적 17경로 빌드 및 diff 검사 통과. 신규 저장소 테스트 추가 없음, API 소스·이미지 변경 없음.
- LF·CRLF 원문 44개 왕복 보존, 화면 전용 문단 제외·경계 보강 44개, 빈 목록과 복잡한 형식 분류 12개 격리 모델 확인 통과.
- 격리 저장·재조회로 말미 문단 활성화와 Backspace의 불필요한 변경 없음, 연속 Enter의 빈 줄 한 개씩 증가, 이후 문장 입력·순서 이동 확인. 네이티브 입력 실행 취소·다시 실행, CDP 한글 조합 중 Enter의 분할 방지 확인. 실제 운영체제 입력기 전체 동작은 별도 미수행.
- 구분선·수식·코드·Mermaid 단축키 유지, 기본 프로젝트 양식의 빈 항목 편집 및 원문 보존 경고 해소 확인.
- 언어 목록 13개·마지막 항목 스크롤·키보드 선택·직접 지정·잘못된 입력 보호 확인. 390px 화면 하단의 위쪽 열림과 실제 터치 선택, 데스크톱 아래쪽 열림 확인.
- 소개 카드 1108·390px 하단 여백 및 긴 소개 겹침 없음, 도움말 1108·700·390px 밝고 어두운 테마에서 가로 넘침 없음. 최종 도움말 28개 항목과 설명 문구 제거 확인, 런타임 오류 없음.
- 최종 전달 SHA의 원격 CI·Pages와 실제 배포 화면 확인은 로컬 인계에 결과 기록 대상.
