# 긴 문장 편집·로그인 유지 보정

## 요청과 원인

- 편집 중 긴 문장과 표 셀의 잘림·블록 겹침 개선 요청
- 문단 입력 높이의 개행 문자 개수 의존과 표의 한 줄 입력 요소 확인
- 로그인 기억하기 요청, 기존 JDBC 세션 비활성 만료 30분과 브라우저 세션 쿠키 확인

## 구현 범위

- 문단·목록·표 셀의 화면 폭에 따른 자동 줄바꿈과 실제 높이 반영
- 표 머리글·본문 입력, 한글 조합, 행열 조작, Enter 이동과 Markdown 저장 계약 보존
- 로그인 화면의 기본 해제된 기억하기 선택과 API rememberMe 전달
- MFA 성공 후 일반 세션 8시간, 기억하기 세션 및 쿠키 30일 적용
- 기존 JDBC 저장·CSRF·세션 ID 교체·쿠키 보안 설정·로그아웃 유지

## 수용 기준

- 데스크톱·모바일 긴 한글/영문/공백 없는 문자열의 마지막 글자 표시 및 블록 비겹침
- 내용 축소·화면 폭 변경 후 높이 재계산, 목록 들여쓰기와 원문 보존
- 기본 로그인·기억하기·미선택 재로그인·실패·로그아웃·만료를 격리 HTTP로 확인
- 비밀번호·MFA 값의 브라우저 저장소 비저장, 인증 전 세션의 장기 유지 방지
- 기존 웹 검사·타입·정적 빌드 및 API 기존 검사 통과
- 실제 운영 API·Pages 반영과 동일 SHA CI 확인, 운영 원고 변경 없음

## 검증

- API 기존 28개 검사·패키지 빌드 및 실행 이미지 빌드 통과
- 웹 기존 7개 검사·타입 검사·격리 공개 API 기반 정적 빌드 통과
- 격리 MySQL·HTTP에서 익명/실패 세션 30분, 기본·미선택 8시간, 기억하기 30일·쿠키 Max-Age 확인
- 세션 ID·CSRF 회전, 기억하기 해제 재로그인, 저장 쿠키 재사용 차단, JDBC 만료 및 API 재기동 보존 확인
- 운영과 같은 Secure·HttpOnly·SameSite=None·Partitioned 유지 및 로그아웃 Max-Age=0 확인
- 1232·390px와 라이트·다크에서 긴 표 셀·문단·목록 자동 높이, 공백 없는 문자열, 축소·확대, 아래 블록 비겹침 확인
- 표 Enter/Escape, 목록 내어쓰기, 임시저장·재조회·재열기 원문 완전 일치 확인
- 실제 로그인 폼의 기억하기 기본 해제·선택·모바일 및 브라우저 정상 종료/재시작 후 인증 유지 확인
- 한글 조합 이벤트 보호·Tab·행 추가/삭제 격리 확인. 실제 OS 한글 IME 입력기 검증은 별도
- 검증 증거 `/tmp/ken-blog-wrap-remember`. 초기 격리 계정 해시 접두어·공개 소개 준비, 브라우저 선택자와 정상 종료 방식 보정 후 통과. 운영 데이터 검증용 쓰기 없음
- 운영 첫 배포 검증의 공개 Swagger 404로 자동 이전 이미지 복구. 내부 Swagger 주소로 검증 경로 수정 후 재배포 확인 대상
- 동일 SHA CI·Pages와 실제 배포 화면 확인 대상
