# P2-03B 이미지 업로드·편집·읽기 화면

## 문제와 시작 상태

P2-03A의 글/편집본 이미지 연결·권한별 OCI 원본 전달 API를 화면에서 사용하는 단계. 현재 본문 이미지는 원문 보존과 안내만 제공하며 업로드 버튼·미리보기·캡션·너비·정렬 없음. 기존 운영 API 교체 없이 격리 환경에서 검증하고 Pages 정적 화면만 반영.

## 구현 범위

- 관리자 글쓰기에서 파일 선택·파일 드롭·클립보드 이미지 붙여넣기를 같은 업로드 흐름으로 연결. JPEG/PNG 한 파일씩, 기존 10MiB 상한·서버 판별 유지. 일반 텍스트 붙여넣기·블록 내부 드래그·표 입력에 영향 없음. 진행·실패·취소 안내, 재시도는 사용자가 명시적으로 실행. multipart CSRF·쿠키 사용, 자동 재업로드 없음.
- 업로드 성공한 READY ID로 이미지 블록 삽입. 업로드 중 경로/원고/로그인 변경 시 결과를 다른 문서에 삽입하지 않음. 성공 응답 전 파일 삭제나 업로드 취소가 발생할 수 있으므로 미확정 OCI 객체 자동 삭제 없음. 진행 중 저장/출간은 막고 원문 손실 없이 안내.
- canonical `![설명|w=60|a=center](attachment:123)` 문법. 기본 너비100%, 정렬center, 너비20~100 정수, left/center/right만 허용. 설명은 대체 텍스트와 캡션에 사용하며 Markdown/구분자 이스케이프를 안전하게 왕복. 설명이 비면 이미지 식별용 대체 텍스트 제공. 기존 단순 `![설명](attachment:123)`은 기본 메타로 해석. 불명확한 메타·외부 URL·복잡한 inline 이미지 블록은 무손실 원문 보존을 우선.
- standalone 지원 이미지 블록의 설명·너비·정렬 수정, 이동·문서에서 제거. 한 단계 접기 내부에서도 같은 조작. 삭제는 문서에서 참조를 제거하는 동작이며 OCI 원본 DELETE는 자동 실행하지 않음. 표/이미지 같은 비문자 블록 앞 Backspace가 내용을 병합/손실시키지 않음.
- 관리자 상세/편집본 DTO의 `attachmentIds`를 검사. 저장 시 실제 Markdown 이미지 노드에서 canonical 첨부 ID를 모아 명시적 전체 목록 전송. 코드 펜스/코드 인용·일반 문자열·링크의 attachment 주소는 이미지 권한으로 추가하지 않음. 안전한 접기 안 이미지 및 유효 참조 이미지도 읽기와 같은 해석을 사용. 최대100개를 넘으면 저장 전 안내. `attachmentIds` 제거가 글별 이미지 읽기 권한 철회라는 의미를 문서화.
- 관리자 미리보기는 관리자 content API, 읽기 화면은 실제 글 ID의 공개 content API 사용. 본문이 허용된 글에서만 이미지 요청. 사용자 입력 URL을 직접 fetch하지 않음. API origin 검증·혼합 콘텐츠 거부·redirect 거부·credentials 정책·no-store 유지. 외부 URL/data/javascript/protocol-relative 이미지는 자동 요청 없이 대체 표시.
- 응답은 JPEG/PNG·최대 크기를 검증하고 blob URL로 표시, 실패시 안전한 안내/명시적 재시도. 컴포넌트 해제·이미지 교체·경로/계정 변경 시 요청 취소와 URL 해제. 비공개 이미지 바이트를 localStorage/전역 영구 캐시에 보관하지 않음. Next 정적 export 유지, `next/image`는 최적화 서버 없는 설정으로 사용.
- 일반 I/O/503·시간 초과와 같은 실패에는 현재 입력 보존. 확인된 401/로그아웃은 기존 인증 계약대로 브라우저 관리자·비공개 데이터를 제거하고 서버에 저장한 편집본은 재로그인 후 재개. 미저장 메모리의 계정 간 보존은 제공하지 않음. 403은 현재 계정을 재확인하고 동일 계정이면 입력 유지. 편집본 저장/출간의 revision·경로 generation 보호 유지. 권한 최종 판단은 Spring이며 클라이언트 표시를 권한 검증으로 대신하지 않음.
- 한국어 JSDoc·작은 역할별 모듈. README·편집/Markdown/첨부 안내·계획 체크리스트 갱신. 새로운 의존성·저장소 테스트·학습 문서 없음.

## 제외 범위

이미지 리사이즈/포맷 변환·CDN·presigned URL·공개 버킷·자동 orphan 삭제·이미지 라이브러리 목록·바이트 캐시·외부 이미지 URL 가져오기 없음. 업로드와 본문 저장을 분산 트랜잭션으로 가장하지 않음. 공개 API 도메인·HTTPS·교차 site SameSite 쿠키·운영 배포는 후속 경계. 중첩 접기 전용 편집·수식/도식/위키는 후속 단계.
