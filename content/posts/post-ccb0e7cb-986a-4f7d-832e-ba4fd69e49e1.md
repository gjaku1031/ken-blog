Vowser의 의도 검색이 다르게 말한 요청을 얼마나 맞히는지 잰 탐색적 평가(1부)와, 그 결과에서 세운 가설을 새 질의로 확인한 확증 실험(2부)의 기록. 둘 다 2026-10-09 측정.

> 낮은 유사도에서 LLM으로 다시 찾는 재검색 분기는, 같은 요청에서 비교하면 바로 순위화하는 분기보다 정확하다는 근거가 없었음. 탐색적 평가에서 보인 큰 차이(41/63 대 5/17)는 분기의 효과가 아니라 요청 난이도가 섞인 결과였음.

## 연구 질문

Vowser는 사용자의 요청 문장을 임베딩해 등록된 작업 의도와의 최고 유사도를 구함. 0.43 이상이면 벡터 검색 결과를 그대로 순위화하고(이하 **순위화 분기**), 미만이면 LLM이 뽑은 키워드로 다시 검색함(이하 **재검색 분기**). 앱은 1위 작업만 실행함. 대문의 핵심 문제 P2(같은 작업을 사람마다 다르게 말함)에 대해 다음을 물음.

- 다르게 말한 요청에서 1위로 맞는 작업을 찾는 비율은 얼마인가(1부)
- 재검색 분기는 정확도를 높이는가. 임계값 0.43은 적절한가. 같은 유사도로 등록되지 않은 작업을 가려낼 수 있는가(2부)

## 1부. 탐색적 평가: 지금 검색은 얼마나 맞히나

분류: 탐색적 평가. 질의와 정답은 실행 전에 고정했지만, 가설과 판정 기준은 미리 정하지 않음.

### 설계

| 구분 | 내용 |
| --- | --- |
| 대상 | 원본 agent 서버(커밋 `d94eaf5`)를 고치지 않고 실행. `text-embedding-3-small`, `gpt-4o-mini` |
| 등록 자료 | 7개 사이트의 합성 작업 16개(날씨 오늘·내일, 뉴스 목록·주제 검색, 코레일 예매·시간표·예약 조회·취소, 정부24 등본·초본·가족관계증명서, 유튜브 검색·좋아요, 쿠팡 배송 조회·주문 취소, 지도 길찾기) |
| 질의 | 합성 한국어 96개. 정답형 80개(작업마다 직접 1·바꿔 말하기 2·간접 1·"A 말고 B" 배제 표현 1), 다의 8개, 미등록 작업 8개 |
| 정답 기준 | 반환 1위의 (사이트, 작업 의도)가 사전 정답과 같으면 정답. 같은 사이트의 다른 작업은 오답. 빈 결과는 오답 |
| 조건 | 상위 3개 요청, 도메인 힌트 없음, 재시도 없음, 한 번 실행 |

### 결과

| 요청 유형 | 1위 정답 | 3위 안 정답 |
| --- | ---: | ---: |
| 직접 표현 | 15/16 | 16/16 |
| 바꿔 말하기 | 20/32 | 26/32 |
| 목적만 말하는 간접 표현 | 7/16 | 8/16 |
| "A 말고 B" 배제 표현 | 4/16 | 16/16 |
| 정답형 합계 | 46/80 (57.5%)[* Wilson 95% 신뢰구간 46.6~67.7%] | 66/80 (82.5%) |

- 1위 오답 34건 중 19건은 같은 사이트의 비슷한 작업끼리 바뀐 경우임. 코레일 작업은 1위 정답이 7/20
- 미등록 작업 8건은 모두 다른 작업을 돌려줌. "주민등록증 재발급"은 "주민등록등본 발급"과 유사도 0.78
- 요청당 왕복 지연은 중앙값 1,348ms(p95 1,984ms)

### 관찰과 다음 가설

최고 유사도가 0.43 이상이라 순위화 분기로 간 요청은 63건 중 41건(65%)이 맞았고, 재검색 분기로 간 요청은 17건 중 5건(29%)만 맞았음. 여기서 "재검색 분기가 정확도를 떨어뜨리고, 임계값을 올리면 정답률이 떨어질 것"이라는 가설을 세움. 다만 두 집단은 서로 다른 요청이고, 유사도가 낮은 요청은 원래 어려운 요청일 수 있어 분기의 효과와 요청 난이도가 섞여 있음. 또 가설을 만든 자료로 그 가설을 다시 검증할 수는 없음. 그래서 2부는 같은 요청에서 두 분기를 모두 실행하고, 새로 작성한 질의로 확인함.

## 2부. 확증 실험: 재검색 분기와 임계값

분류: 확증 실험. 가설·기각 기준·분석 스크립트를 실행 전에 커밋([`7a249b1`](https://github.com/gjaku1031/ken-blog/tree/7a249b1/docs/experiments/2026-10-09-vowser-intent-threshold))으로 고정하고 한 번 실행함.

### 가설과 기각 기준

| 번호 | 가설 | 판정 기준 |
| --- | --- | --- |
| H1 | 같은 정답형 요청 80개에서 순위화 분기의 1위 정답이 재검색 분기보다 많음 | 순위화만 맞은 쌍이 더 많고, 짝지은 정확 McNemar 검정 p < 0.05면 지지 |
| H2 | 재검색을 끈 경우(임계값 0)의 1위 정답은 0.43 이상이고, 0.60에서는 0.43 이하임 | 두 부등식이 모두 성립하면 지지 |
| H3 | 최고 유사도로는 미등록 요청과 정답형 요청을 잘 가르지 못함 | ROC AUC < 0.80이면 지지 |

### 설계

| 구분 | 항목 | 내용 |
| --- | --- | --- |
| 독립변수 | 분기 | 순위화, 재검색. 요청마다 유사도 검색·LLM 의도 분석을 한 번 실행하고, 같은 상태에서 두 분기를 각각 실행함 |
| 독립변수 | 임계값 | 0, 0.30~0.60(0.05 간격과 0.43), 1.01(항상 재검색). 임계값은 분기 선택에만 쓰여 기록에서 계산함 |
| 종속변수 | 정확도 | 1위 정답, 3위 안 정답(1부와 같은 기준) |
| 종속변수 | 판별력·비용 | 최고 유사도, 재검색 비율, 지연 |
| 통제 | 코드·모델 | 원본 함수를 고치지 않고 불러옴. LLM temperature 0, 요청당 한 번만 호출해 두 분기가 같은 결과를 씀 |
| 통제 | 자료 | 1부와 같은 작업 16개를 빈 Neo4j에 새로 등록. 검색 후 가중치 증가는 부르지 않아 순서 효과를 없앰 |
| 표본 | 새 질의 104개 | 1부와 같은 유형 구성의 정답형 80개·다의 8개, 미등록은 16개로 늘림(가까운 영역 8·먼 영역 8). 1부와 같은 문장은 없음 |

### 해석

- **H1을 지지하지 못함.** 같은 요청에서 비교하면 순위화 분기가 52 대 45로 앞섰지만, 결과가 갈린 29쌍 가운데 18 대 11은 우연으로도 나올 수 있는 차이임. 1부의 65% 대 29%는 분기의 효과라기보다 유사도가 낮은 어려운 요청이 재검색으로 몰린 결과였음. 탐색에서 본 차이를 같은 자료로 결론 내렸다면 틀린 주장을 했을 것임
- **H2는 지지했지만 차이가 작음.** 재검색을 끄면 정답률은 같고(52 대 52) 지연은 중앙값 약 100ms 줄어듦. 현재 자료에서 재검색 분기는 정확도 이득 없이 LLM 키워드 검색 비용만 더함
- **H3은 경계에 있음.** AUC 점추정은 0.80 미만이지만 신뢰구간 상단이 0.87이라, 판별력이 낮다고 단정하기는 어려움. 다만 미등록 요청 16개 중 6개(37.5%)가 0.43 이상이라, 현재 임계값을 '모르는 작업' 판정 기준으로 쓰면 이 요청들은 등록된 다른 작업으로 실행됨
- **계획에 없던 관찰**: 1위 정답은 임계값 0.35에서 56으로 가장 높았음. 사후에 본 값이라 이 자료로 "0.35가 최적"이라고 주장하지 않음. 확인하려면 새 질의로 다시 실험해야 함
- 정확도를 높이려면 임계값 조정보다, 같은 사이트의 비슷한 작업과 "A 말고 B" 같은 배제 표현을 구분하는 방법이 더 필요함. 두 경우에서 오답이 가장 많았음

## 타당성과 한계

Shadish·Cook·Campbell(2002)의 네 분류로 정리함.

- **내적 타당성**
  - 분기와 요청 난이도의 혼동은 2부에서 같은 요청에 두 분기를 모두 실행해 없앰
  - 실행기가 원본 서버와 다르게 동작할 가능성은 1부 자료의 재현 점검(95/96 일치)으로 확인함. 검색 후 가중치 증가는 의도적으로 뺐음
  - 첫 실행은 평가용 Neo4j에 APOC 플러그인이 없어 원본 코드가 DB에 연결하지 못하고 실패함. 실패 기록을 보존하고 APOC를 넣어 다시 실행함(1부)
- **외적 타당성**: 등록 작업 16개와 질의는 모두 합성 자료이고 실제 사용자 발화나 음성 인식 결과가 아님. 작업이 수백 개로 늘거나 실제 말투가 섞이면 결과가 달라질 수 있음
- **구성 타당성**
  - 앱이 1위만 실행하므로 1위 정답을 주 지표로 둠
  - 질의는 에이전트가 작성했고, 2부 질의는 1부 결과를 본 뒤 작성함. 같은 유형 구성과 작성 규칙을 따랐지만 작성자의 편향은 남음
- **통계적 타당성**: 정답형 80개, 미등록 16개라 작은 차이는 구분하지 못함. 검정력 분석은 하지 않음
